- **One correction at a time.** The Draft Lab design was never written down; it grew from JL's corrections (89 dated comments), so the same kind of fault came back in the next view.
- **Fixed in one place, not the others.** Name-year citations were fixed in one view on 11-13 and asked for twice more on 11-15; the name lookup still has two copies (server and skill).
- **Many sessions, one set of files.** Sessions edited the same Draft Lab files at once: a stale import broke 5602, my variable broke the Story view, and two opposite rulings on S and s met.
- **Live hosts ran half-edited code.** Hosts were restarted while files were being edited, so JL sometimes saw a broken or an older page.
- **Checked on copies, not on what JL sees.** Most checks ran on a private server or a copy; tests were updated to match new behaviour four times.
