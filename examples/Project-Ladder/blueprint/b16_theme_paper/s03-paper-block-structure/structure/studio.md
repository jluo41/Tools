# Paper Studio organization

These are the design topics of an actual Paper Block. Each band groups design questions; its Studio type describes the content of an individual topic. Names in 〈 〉 are proposed. Create only topics needed by the work; omit empty bands. Existing topics keep their identifiers.

| Band | Name | Studio type | One topic addresses |
| --- | --- | --- | --- |
| s0N | 📖 Story | 〈Argument Design〉 | Connect the question, contribution, competing explanations and narrative. |
| s1N | 📚 〈Evidence〉 | 〈Evidence Plan〉 | Identify the evidence each claim needs and its source. |
| s2N | 📊 Display | 〈Display Design〉 | Compare figures and tables that communicate the claims. |
| s3N | ✍️ Writing | 〈Narrative Design〉 | Explore venue fit, section structure and revision choices. |
| s4N | 🎤 Presentation | 〈Presentation Design〉 | Develop the argument for a talk, poster or other audience. |

A topic concerning only one Job belongs beside that Job’s Tasks. Block-level topics compare candidates or define shared choices. Studio references work records; it does not duplicate their evidence, approvals or selection receipts.

The shared hai-studio contract owns topic folders and numbering. The Blueprint’s own Block Structure / Preview / Skills bands do not become the bands of this research Block.
