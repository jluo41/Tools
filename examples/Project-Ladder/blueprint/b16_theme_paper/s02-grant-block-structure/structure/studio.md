# Grant Studio organization

These are the design topics of an actual Grant Block. Each band groups design questions; its Studio type describes the content of an individual topic. Names in 〈 〉 are proposed. Create only topics needed by the work; omit empty bands. Existing topics keep their identifiers.

| Band | Name | Studio type | One topic addresses |
| --- | --- | --- | --- |
| s0N | 🎯 〈Opportunity〉 | 〈Call Fit〉 | Compare funding requirements with the proposed research. |
| s1N | 💡 〈Aims〉 | 〈Aims Design〉 | Connect the questions, aims, innovation and success criteria. |
| s2N | 🔬 〈Approach〉 | 〈Study Design〉 | Compare methods, work packages, milestones and alternatives. |
| s3N | 📚 〈Evidence〉 | 〈Evidence Plan〉 | Assess preliminary support and identify the next evidence needed. |
| s4N | 🤝 〈Resources〉 | 〈Resource Plan〉 | Connect expertise, partners, facilities and costs to the work. |
| s5N | 🌍 〈Impact〉 | 〈Impact Design〉 | Trace intended beneficiaries, use and outcomes. |
| s6N | ✍️ 〈Narrative〉 | 〈Narrative Design〉 | Develop the application argument, section relationships and key displays. |

A topic concerning only one Job belongs beside that Job’s Tasks. Block-level topics compare candidates or define shared choices. Studio references work records; it does not duplicate their evidence, approvals or selection receipts.

The shared hai-studio contract owns topic folders and numbering. The Blueprint’s own Block Structure / Preview / Skills bands do not become the bands of this research Block.
