# Grant <!-- root -->

- Story <!-- story -->
  Job group.
  - 〈Shared argument〉 <!-- story-job -->
    Job type: 〈Story〉. Its question, contribution and narrative are content; no automatic Tasks.
- Evidence <!-- evidence -->
  Job group.
  - 〈Shared evidence〉 <!-- evidence-job -->
    Job type: 〈Evidence〉. A consolidated execution contract is required.
    - 〈Values〉 <!-- values -->
      Task group type: 〈Content〉.
      - 〈Reported estimates〉 <!-- estimates -->
        Paper's observed value field requires reconciliation with the shared numeric executor.
    - 〈Citations〉 <!-- citations -->
      Task group type: 〈Content〉.
      - 〈Claim sources〉 <!-- sources -->
        Paper's citation evidence field requires reconciliation with the numeric evidence executor.
    - 〈Checks〉 <!-- checks -->
      - 〈Evidence audit〉 <!-- audit -->
        Question-specific consumer checks; source Results retain ownership.
- Display <!-- display -->
  Job group.
  - Main <!-- main -->
    Job type: Display. Appendix and Explore are sibling Jobs when required.
    - 〈Figures〉 <!-- figures -->
      Task group type: 〈Content〉.
      - 〈Figure title〉 <!-- figure -->
        Task type: 〈Display asset〉; final-asset routing requires definition.
    - 〈Tables〉 <!-- tables -->
      - 〈Table title〉 <!-- table -->
        Task type: 〈Display asset〉.
- Writing <!-- writing -->
  Job group; each version is a Job.
  - 〈Application version〉 <!-- writing-job -->
    Job type: Writing Version.
    - 〈Main text〉 <!-- text -->
      Task group type: 〈Content〉.
      - 〈Section title〉 <!-- section -->
        Task type: draft; names follow the destination requirements.
    - 〈Appendix〉 <!-- appendix -->
      - 〈Supplementary section〉 <!-- supplement -->
        Task type: draft.
    - Review <!-- review -->
      - 〈Response to comments〉 <!-- response -->
        Prose uses draft; comments retain their original identity.
    - Submission <!-- submission -->
      - 〈Cover letter〉 <!-- letter -->
        Task type: draft.
      - 〈Portal preparation〉 <!-- portal -->
        Packaging execution contract requires definition; no permission to send.
- Presentation <!-- presentation -->
  Job group.
  - 〈Slides, Video or Poster〉 <!-- presentation-job -->
    Job type: 〈Presentation〉; the format is the Job name.
    - 〈Content〉 <!-- presentation-content -->
      - 〈Script or asset〉 <!-- presentation-task -->
        Prose uses draft; production uses a proposed 〈Presentation asset〉 contract.
