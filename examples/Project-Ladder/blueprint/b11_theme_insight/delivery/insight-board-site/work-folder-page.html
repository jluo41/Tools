From a folder to a page

The workbench keeps no copy of the work. Each page is read from the Block's folders every time it opens, so the Folder System is the UI System's data model.

  1. 1

    A folder

    Its face says what it is: board.md's board-kind:, or the name's pattern, jNN_…, tNN_…, sNN-… or cNN_….

  2. 2

    A level

    Board, Job, Task, Question Book, Release, Question, Data Prep, Prep, Step or Prep Task. A Studio topic and a Chat belong to their Block.

  3. 3

    A page

    /_board/workbench?path=<folder>&layout=focus, with Report, Work, Studio and Delivery, a Runs panel, the Files section and the Skills rail.

  4. 4

    Its views

    The level's views. Report draws them as numbered sections; Work draws each as ⚙️ Process then 📊 Results, with the MindMap last.
