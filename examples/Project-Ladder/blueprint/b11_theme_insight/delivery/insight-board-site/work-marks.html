Marks, not words

A page shows a state with a mark beside the item, never a sentence about it. Words stay only for a required action or the reason something failed.

  • ✅donea Run ok, a page checked, a version signed
  • ⬜not yet, or stoppeda planned Run, a page not written
  • 🏃runninga Run in progress
  • ❗void or stalea failed Run, a report written before its result changed
  • 🙋waits on youa signature, a decision; gathered in the tray beside the title
  • 🧵a chat touched ita kept chat or a pass wrote here; a click opens those sessions
