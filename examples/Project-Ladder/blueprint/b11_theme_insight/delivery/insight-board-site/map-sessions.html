The Session view

An episode is one goal worked in one sitting. The Session view lists them, newest first, each with its date, its goal, and the folders and cards it touched as links.

What counts as an episode

A chat and a pass carry the same front matter (session, provider, date, goal, paths, cards), so the view reads both the same way. The 181 segment Runs an episode may start are folders it touched, never episodes.

Where it shows

  • Studio › Sessions, and the Sessions part under a focus page's Files, filtered to that folder.
  • 🧵 on folders in the Folder view: every folder and file a paths: names, and the folders above them.
  • 🧵 beside an item on a page, by its card address. Structure rows (Jobs, Tasks, Runs, folds, tabs) carry none.
  • Never a transcript. A transcript can hold printed rows, which an insight page must never show.
