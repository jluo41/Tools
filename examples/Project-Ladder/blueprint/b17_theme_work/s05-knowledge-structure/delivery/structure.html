Job group type ›〈Practice theme〉

For
Group independently deliverable practice Jobs around one application question.
Holds
A shared goal, related learning Studios, and needed build, check or documentation Jobs; the group does not execute.

A possible A2UI group is 〈Interactive card〉 using j0N. A simple practice can show a Job directly without invented members.

Job type ›〈code〉

Holds
Tasks whose Runs produce code that runs; a result a user can call.
Open

Job type ›〈doc〉
