Resources Band
--------------
Resources comes first, followed by Concepts, Methods, Connections and Applications, and Questions.
The ranges are s0N, s1N, s2N, s3N and s4N. A Questions topic keeps the learner's question in their own words and answers it from the Resources. Bands group actual Studio topics and add no folders.
Do not add a second same-named Resources Studio or a separate Sources view.

Resource topics record original links, versions and precise sections, pages or timecodes.
Existing Related and Discovery records retain ownership; learning topics cite the same records.
Unknown locations remain unknown. A source does not automatically require its own Studio.

Actual Studio acceptance
------------------------
The A2UI Studio must contain real topic folders, English learning notes, diagrams and bound views.
A list of proposed topics under Report / Plan + Results does not satisfy that requirement.
Report keeps a brief summary and links. The example link opens section=studio.
Chat may use Chinese; authored page labels, explanations and diagrams use English.
