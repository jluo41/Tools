# Types of a Work Block (Discovery)

The four lists a Work Block (Discovery)'s Jobs and Tasks are sorted by (s71 · Studio Type: Block Structure, Structure › Job-Task).
`## ` is a level, `### ` one type of it: `for:` what it is for, `holds:` what a Job or Task of that type must hold. A
level this Block type does not use says so with a `none:` line. Read by `block_types_pages.py` and
`block_types_check.py`.

None of these names is agreed yet: each was read from the example Block, carries `agreed: no`, and shows as 〈name〉
until JL agrees it (then `agreed: yes`, and the brackets go).

example: examples/Project-Ladder/discovery/b01_example_discovery

## Job group type
none: a Discovery Job is itself the inquiry that groups its research questions

## Job type
field: `job-type:` on the Job face; no Job of the example Block names one yet

### Inquiry
agreed: no
for: answer one question from outside sources.
holds: its research questions as Tasks, and what they add up to.

## Task group type
none: the example Block's Jobs do not group their Tasks

## Task type
field: `discovery_type:` on the Task face

### topic-summary
agreed: no
for: say what the sources together support on one research question.
holds: one Run per paper or source read, each with its card, facts and citation entry; then the summary.

### source-map
agreed: no
for: find and list the sources worth reading on one research question.
holds: the candidates found, which were admitted, and why.
