〈skill〉 ›ref/

What
The skill's reference files, one fold each; an opened fold shows the file.
Why
The left stays as short as the skill's top level; the folds list what the folder holds before any is read.
When
the skill has a ref/ that holds a file
Must show
  1. the tab ends in a slash, as every folder does
  2. one fold per file, named by the file, in name order, all closed at first
  3. an opened fold shows the file itself
  4. no ref/ tab when the skill has no ref/ or it holds no file
From
the files directly in 〈skill〉/ref/, read live
Check
the tab names the skill's own ref/ folder
