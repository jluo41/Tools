## Plan + Results

### Practice scope

The Studio explains a selection-card interaction. A future practice can test fixed messages, a local value edit,
an outgoing action and an incoming update. Create execution records after choosing a compatible execution
contract and pinning the implementation. The learning content is not a record of a running A2UI demo.
