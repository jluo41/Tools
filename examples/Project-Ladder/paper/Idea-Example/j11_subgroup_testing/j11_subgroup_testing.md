## Topic

Do prespecified subgroup stress tests reveal model failures that an overall performance average conceals?

The candidate is a hypothesis for this example. Prespecified subgroup evaluations may identify practically important error gaps hidden by the overall average.

**Method:** Define subgroups before analysis; measure uncertainty for each; compare individual gaps with the aggregate result.

**Minimum experiment:** A fixed evaluation protocol using one dataset, declared subgroup boundaries and uncertainty intervals.
