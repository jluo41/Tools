# Example Seed Programme

This fictional call supports the Workbench example; it is not an active funding opportunity.

## Application materials

- Letter of intent: question, aims, proposed comparison and expected contribution.
- Full application: specific aims, research approach, milestones and resource justification.
- Review: resolve feedback against the selected application version.
- Submission: prepare a cover letter and required attachments within that Writing Job.

## Review criteria

The question must be falsifiable; the comparison must address a named alternative; the requested resources must connect to the work. Proposed outcomes must stay separate from preliminary evidence.
