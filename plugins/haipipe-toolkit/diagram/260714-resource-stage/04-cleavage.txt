THE RULE
========

```text
     🧱 a question that CHANGES what exists on disk            →  RESOURCE
     ⚖️  a question that READS what exists and MOVES A         →  CLAIMS
        CLAIM'S STATUS
```

  The toolkit had already written this table — and filed it under the WRONG stage
  (claims/SKILL.md:218):

```text
        input     task-for-data   → 🧱 RESOURCE   builds an AIData
        method    task-for-algo   → 🧱 RESOURCE   builds a capability
        fit       task-for-fit    → ⚖️  CLAIMS     trains the paper's model  (AMENDED 07-15)
        evaluate  task-for-eval   → ⚖️  CLAIMS     produces the claim's STATUS
```

  🛑 RESOURCE MAY NOT RUN `task-for-fit` OR `task-for-eval` (no training, no eval).
     That is what stops the stage swallowing the paper. Without it,
     "prepare the resources" expands until it means "do the research", and claims
     becomes a formatting step. Resource asks whether the ingredients EXIST and can
     CARRY the claim; the experiment (train + eval) is claims'.

  🛑 RESOURCE NEVER EXECUTES ANYTHING.
     No /haipipe-data, no /haipipe-nn, no /haipipe-task, no scaffolding.
     It writes QUESTIONS. The probe layer dispatches them, to the task/discovery
     orchestrators, across a clean-context wall.


❌ THE ANTI-PATTERN — PP04, and why bundling is fatal
=====================================================

  PP04 self-labelled itself "bundled fit+eval". The bundling IS why its null was
  uninterpretable:

```text
   🏗️  fit   (build the checkpoint)   ─┐
                                       ├─ ONE RUN ──▶ 📊 null result
   ⚖️  eval  (does it beat baseline)  ─┘                    │
                                                            ▼
                          ❓ did the null come from the MODEL, or from the CORPUS?
                             (AIREADI: 40–94, zero under-40s — see 02-worked-example)
                          🤷 UNANSWERABLE. The run cannot tell you.

   ✅ SPLIT:  🧱 resource asks "can this corpus CARRY a lifespan clock?" → ❌ NO
                 …and the eval is never dispatched. Cost: 30 seconds.
```
