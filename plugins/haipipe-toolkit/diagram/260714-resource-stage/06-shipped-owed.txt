🚨 THE FOUR TRAPS — why those fixes exist
=========================================

  Every one FAILS SILENTLY: it does not error, it reports success while checking
  nothing. All four are defused. Kept on the record so nobody "simplifies" one away.

  🚨 TRAP 1 — THE FALSE GREEN   ⬅ would have embarrassed us on day one
     ZERO live papers have a machine-readable Gate Ledger (0 `| yes |` cells,
     workspace-wide). So stage-strip.sh ALWAYS falls through to index-comparison:
     "this stage sits BEFORE current_layer ⇒ it must be done."
     Insert `resource` before `claims`, and every paper at `current_layer: claims`
     instantly renders:
           resource ✅   ⬅ A GREEN FOR A STAGE THAT HAS NEVER RUN.
                            On 4 live papers. On commit day.
     ✅ FIX: demand an ARTIFACT ON DISK, not just a position in the list.
        "Before the frontier" is EVIDENCE of doneness, not proof.
          elif [ "$i" -lt "$cur_idx" ]; then
            if [ "$k" = "review" ] || stage_has_artifact "$k"; then m="✅"; else m="⬜"; fi
        (`review` is post-submission and owns no folder — hence the exemption.)
        VERIFIED: all 5 live papers render `resource ⬜`. ScalingLaw unchanged.

  🚨 TRAP 2 — THE SILENT BLANK
     stage-strip.sh had NO error path for an unknown stage name: `cur_idx` inits to
     -1 and no branch caught it.
     LIVE PROOF, before any of this work: Paper-CGMtoHbA1c's
     `current_layer: write/edit` is absent from keys= ⇒ the strip renders EVERY stage
     ⬜ and exits 0. Silently. A paper at its frontier reports as untouched.
     ⇒ the moment any paper wrote `current_layer: resource` without the keys= edit,
       its console would go BLANK with no warning.
     ✅ FIX: ship keys= in the SAME commit + a `cur_idx == -1` WARNING to stderr.

  🚨 TRAP 3 — THE DEAD PROBE PHASE
     The probe worker reads `per-stage-dispatch.md` to pick its mode + lanes. An
     UNREGISTERED stage silently inherits "light, no lanes" — so the resource PROBE
     phase would quietly DO NOTHING, and look like it worked.
     ✅ FIX: a `resource` row in that table is MANDATORY.
        VERIFIED: per-stage-dispatch.md:85 carries it.

  🚨 BONUS — THE ORPHANED POINTERS
     7 live forward-pointers in seed _LOGs. ALL say "CLAIMS". One uses a UNICODE
     arrow (→, not ->). A strict ASCII/RESOURCE-only grep silently orphans all seven
     — including BOTH of Paper-PersonalizedGlucoseModel's.
     ✅ FIX: the DRAFT consume-grep must be glyph- AND legacy-tolerant.
