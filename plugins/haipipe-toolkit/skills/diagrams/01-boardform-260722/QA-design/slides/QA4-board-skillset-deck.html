Why it exists

Decisions die in chat

😶 Unfindable

"We settled this last month," but where? Nobody can point at it.

🔁 Re-argued

The same question returns every few weeks, and costs the same hours again.

🧑‍🚀 Unreadable

A new collaborator cannot reconstruct why anything is the way it is.

Each card is a real failure we hit. The board is the fix for all three at once: the ruling has an address.

The shape

One page, four sections, one place to rule

📂 The board

A folder: board.md lists groups of Q pages. It builds to a static site anyone can open.

📄 The page

One question. Opening · Diagram · Content · State: the same skeleton on every page.

⚖️ Decision Now

Open choices sit as rows in State. A human ticks a row; the tick IS the ruling.

🧾 The trail

Log lines, dated. What changed, when, on whose word, kept on the page it changed.

Stress: the human never edits machinery. They read prose and tick rows. Everything else is the agent's job.

The skill set

Three layers of skills run it

⚙️ haipipe-board

The engine: build the site, serve it, check every page mechanically.

📐 haipipe-board-page

The page contract: what any page owes its reader, whatever it is about.

🔀 the verbs

Routing, regrouping, meeting capture: how things move between pages.

If they remember one name, make it haipipe-board-page: the contract everything else specializes.

The one design idea

Page = Type × Phase

🧬 TYPE · what it is

Found from the file itself: stage · section · venue · skill · meeting · literature · value · display · slide. Nine so far; a five-part test admits a new one.

🌀 PHASE · what it needs now

Decided by authority: DRAFT borrows, PROBE earns, REVISE pays only with what landed, CHECK audits and alone may close.

The skill finds both and loads the right contract; nobody memorizes the matrix.

Type is stable identity; phase is current need. The same page moves through phases; it never changes type.

How work happens

Agents draft · humans rule

1 · CREATE

A question worth keeping gets a page, in the group that owns it.

2 · WORK ON

The right type + phase contract loads; the page improves under audit.

3 · RUN

A bounded loop of phases with receipts. Hitting the limit is a stop, never a pass.

The human's whole interface: read the page, tick a Decision Now row.

Bounded matters: the loop cannot declare itself done by exhaustion. Only CHECK closes, and it audits receipts.
