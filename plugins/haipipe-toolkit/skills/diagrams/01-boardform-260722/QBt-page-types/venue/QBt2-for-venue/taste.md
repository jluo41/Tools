# JIS Desk Taste

🚫 FABRICATED. No editor at any journal wrote a word of this. See
`README.md` in this folder.

What the handling editor wants on their desk before a paper reaches a reviewer.
Distilled from this pack's `README.md` and `style-profile.md`. JIS publishes one
category, the Observation, and it screens on recountability above novelty.

## Yes (editor leans forward)

- A mechanism, named, with the thing that would have to be true for it to be
  wrong stated in the same paragraph.
- A corpus a stranger could recount: the population, the exclusions and their
  policy, the denominator, and the command that produced the table.
- A Limits block that caps the paper's own verb, written before the finding and
  read straight after the abstract.
- A claim verb that matches the design. An observational design says "is
  associated with"; only an assigned design says "reduces".
- One display per claim, each carrying the command that regenerates it.

## No (desk-reject signals)

- A causal verb over an observational design. This is the single most common
  desk reject at JIS, and the title is where it is caught: a paper asking
  "does X reduce Y?" over data where X was never assigned is returned before
  review, whatever the body says.
- A table nobody can recount: no denominator, no exclusion policy, or a number
  that appears in the prose and in no artifact.
- A Limits block written as an apology at the end. Limits that arrive last read
  as a concession; JIS reads them as part of the claim.
- A finding whose evidence is a screenshot, a pasted number, or a figure with no
  regenerating command.
- Novelty framing. "The first study to" is not a JIS argument, because the desk
  does not screen on novelty.

## The one-sentence test

"Could a stranger, using only what this paper deposits, recount the table and
get the same numbers, and would the paper's own verb survive them?"

The desk buys recountability, and it treats an overclaimed verb as a defect in
the evidence rather than a defect in the writing.
