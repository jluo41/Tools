Content §1

One scene per owner, in the owner's folder

📄 Page drawing

⟨page⟩/draw/⟨id⟩.excalidraw — an ordinary file, useful opened by itself.

🗺 Group drawing

⟨group⟩/draw/group.excalidraw — layout plus an import list naming each page's scene.

🧭 Board map

board.excalidraw — the Index page's overview scene.

🖼 Image bytes

assets/⟨owner⟩/ — pasted images kept out of the scene file.

A page with no drawing yet gets an empty scene created on first open — never a missing file to trip over.

Four file kinds, and each has exactly one owner whose folder it lives in. Stress that the group file holds only its own layer and an import list — page content is referenced, never duplicated. The empty-scene-on-first-open rule means the split always has something to show.

Content §2

The Draw split: beside the page, never inside it

🖌 Open

Plugin ▾ → Draw, or the Draw tab in the right pane.

✏️ Edit

Draw on the canvas; saves go to this page's own scene file.

✨ Generate

The Draw-it button: Claude draws the page's ## Diagram; an ask is optional.

🔄 Follow

Navigate to another page and the canvas follows it.

The split shows which file it saves to before you draw — and Draw-it refuses to overwrite a drawing a person made by hand.

This is the one door to the real drawing in the viewer. The safety story matters more than the features: you always see the target file before a gesture lands, so nothing can end up in another page's scene. Generated scenes regenerate freely; hand-made ones are protected.

Content §3

The group view is composed, never copied

💾 Stored

Each page's scene, the group's own layer, and the placements.

⚙️ Derived

One composed view, rebuilt on every open.

🔒 Identity

Every element keeps its owner, so edits route home.

Editing happens in one visible mode at a time — arrange pages, edit the group layer, or enter one page's scene — and only that owner's file receives the save.

The composed view is a derivation, so there is nothing to merge or import by hand — a page save simply shows up on the group's next open. The mode discipline is what makes multi-file editing safe: at any moment exactly one file can receive your changes, and the canvas tells you which.

Content §4

Saves are checked, never blind

📥 Opened

The editor records the revision it loaded.

📤 Save

Carries owner, that revision, and the changed elements.

✅ Accepted

Only if the file has not moved since.

⚠️ Conflict

Someone else saved first — reload and compare.

The chat pane receives the same owner address as the canvas, so asking it to change a drawing routes to that drawing's own file.

Two people on the same drawing cannot silently overwrite each other, because every save declares where it started from. And note the last line — the chat and the canvas share one owner address, so Claude edits land in exactly the file you are looking at.
