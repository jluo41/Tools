Law

The rules that make nesting safe

  • A question is a Q*.md file at ANY depth; membership stays by path.
  • Segments starting _ or ., and fig/, are not part of the board.
  • Pages list bare filenames; a duplicate basename warns and keeps the first.
  • The page carries the board-relative posix path; serve.py vets it — no absolute, no .., basename must match Q*.md.
  • Archiving a nested page flattens it into the top-level _archive/.

The vetting line is the write-back guarantee: comments can only ever land inside the board.

Slow down on the vetting rule — it's what lets a server accept a path from a browser and still write safely. The duplicate-basename rule is the one people trip on: the Pages list stays flat-looking even when the tree isn't.
