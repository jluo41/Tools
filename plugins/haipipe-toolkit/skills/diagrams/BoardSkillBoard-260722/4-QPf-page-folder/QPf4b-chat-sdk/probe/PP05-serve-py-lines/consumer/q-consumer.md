# Q-consumer · PP05-serve-py-lines

## C5.P1.B7 · "2938 lines across 20 HTTP routes … chat one job out of seven"
The second argument for staying in Python is a size argument, and it is carried by
one vintage of numbers: 2938 lines, 20 routes, seven jobs, plus a nine-row block of
per-area line counts, all "as measured then", 260731. The page then says the file
has since been split and that `cli/serve.py` is "a 496-line HTTP router" today,
with no date and no command at all. So the page holds two vintages, and neither
names a commit anyone could re-run.

## Stake
What this page loses: the cost side of the language decision, which is what makes
the five Aims A4.1 through A4.5 Python work rather than a rewrite. The argument
"going JS means porting an Excalidraw round trip, a SQLite database, a
sentence-marking engine and a PTY, and none of them touch Claude Code" is a claim
about proportions. If the split moved those proportions, the sentence stops being
true and nobody can tell from the page, because the numbers under it predate the
split by weeks.
