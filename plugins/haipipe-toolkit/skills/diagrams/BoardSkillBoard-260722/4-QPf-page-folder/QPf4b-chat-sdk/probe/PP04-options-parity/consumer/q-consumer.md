# Q-consumer · PP04-options-parity

## C5.P1.B5 · "There is nothing we would gain by switching"
This is the whole division's verdict, and one number carries it: "`ClaudeAgentOptions`
in Python carries 47 options, and they cover every flag the plugin's arg builder
emits". The page introduces it as "Parity, checked rather than assumed", and then
prints neither the check nor its date. 47 is a count of a package that ships new
releases, and "covers every flag" is a claim about a bundle the page last read at
v2.1.220 on 260731.

## Stake
What this page loses: the language decision itself, and with it the shape of
A4.1 through A4.5. Every one of those Aims is written as Python work; each
unmatched flag is a hole that `extra_args` has to paper over, and if the
unmatched set is not empty the advice "stay in Python" becomes a trade rather
than a free choice. The division's 📌 line would have to be rewritten.
