# Q-consumer · PP01-extension-bundle-bytes

## C1.P1.B5 · "That 245MB file is not a special build, and it is not a second product"
Content 1 prints a three-line file listing (`webview/index.js` 5MB, `extension.js`
2.5MB, `resources/native-binary/claude` 245MB) and dates the whole division to
"read from v2.1.220, 260731". No command, no install path and no measurement date
sits beside any of the three sizes, so a reader cannot re-derive one of them. The
extension installed on this machine today is 2.1.233 / 2.1.234 / 2.1.235, and
2.1.220 is not among them, so the page describes a build nobody can now point at.

## C5.P1.B2 · "ships as one 2.5MB minified bundle"
The same listing is the evidence for the first of the three "JS version" answers.
The size is the whole reason the bullet reads as a fact rather than an impression.

## Stake
What this page loses: the reading that the plugin is "only a shell around an
engine we run", which is what lets §4's plan be FOUR STEPS (A4.1 the session
host, A4.2 the streaming verbs, A4.3 rewind, A4.4 @-mentions, A4.5 plan mode)
rather than a port of something we have not looked inside. If the shipped bundle
is not what the page says it is, every one of those five Aims is scoped against a
build that no longer exists.
