Chapters 1–2

The constitution, then the board altitude

🧭 QA · six premises

geography · language · birth · the round · identity · the roster. No page owns a deliverable — delete one and nothing breaks today; a reader gets lost tomorrow

🏛 QB · one folder, one board

board.md is the only authored thing at this altitude; the Index is DERIVED on every build, so the front door cannot lie. Design-1 and Design-2 hold the shipping units

QA's cautionary tale is QA5: one defect class reported four times in different clothes, because identity lived in names and empty lookups stayed silent. QA3 exists because "work finished" and "board ready to hand back" came apart three times in one day.

Chapters 3–5 · the page

What it says, where it lives, how it moves

📐 QPs · structure

the fixed sections, and the two kinds that change what closing means — five kinds became two on 260815

📂 QPf · folder

the plugin law: draw, slide, chat, display… material lands in plugins, and discovery never enters one

🔁 QPw · workflow

draft · probe · revise · check, and the dispatched agents that run them — one writer, one page

The mirror kind died of a measured disease: five Openings out of one template, because a page that decides nothing has no question to ask.

QPs works specimen-first: build one real page, then write the contract it taught you. QPw was born owing its debt on purpose — the four phase contracts ship as skills with no page arguing them yet.

Chapters 6–7

The sentence, and the round trip

✏️ QS · sentence-grained memory

the smallest thing with an address, a record, and a card — archived, never deleted. It is why the 260815 restructure moved most of the board while every old citation still resolves

⚙️ QC · md in, site out

markdown → build → board/ → a reader's click → one line of markdown back. HTML never travels into markdown; every generated byte is disposable

QC's founding ruling was JL's, on seeing 25 loose scripts: "这个结构很差" — and the top level emptied into cli/ and tests/ the same day. The write path lands exactly one line in one file; QS4 exists to prove every shape of that claim.

Chapters 8–9

The served board, and the evidence lane

🖥 QO · two audiences, one server

you working (split workspace, status strip) and others arriving (hosting, mounts). The bind address is the only access control there is — the listener stays on loopback

✅ QF · what actually ran

the gate after every change, a zero-context agent finding the door, a real browser, a real chat turn. Mechanical checks catch state; only a fresh reader catches prose

QF's founding incident: a whole feature was built and running on 260726 while its page still said nothing is built — the board and the machine told two different stories. Every gate here pairs a mechanical check with a fresh reading.
