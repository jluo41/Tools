Why this board exists, and how to read it

Design talk with an agent is smart and forgetful. A board gives every decision an address instead: one topic is one folder, one decision is one page with a state anyone can read. This chapter is the front door.

§1 · Why a board

A decision that lives only in a chat is already lost

💨 The problem

The next session starts from nothing — the choice gets re-argued, quietly reversed, or forgotten. The loudest most recent chat wins.

🏠 The fix

One topic = one folder, one decision = one page, with a state line (🔴 🟡 ✅ ⏸️) anyone can read without reading the page.

🎓 The loop

Argue on a page, settle, graduate: the Law is copied into the skill that ships, and only then binds. The chat can be forgotten because the page cannot.

🧪 The stranger test

A stranger opens the generated site and knows: what is decided, what is open, and where to argue. Counts are computed on every build, so the front door cannot lie.

This board's own history is the evidence: "the work is finished" came apart three times in one day before QA3 gave the round a gate.

Start with the failure, because everyone in the room has lived it: a good conversation, a real decision, and then a new session that remembers none of it. The board is not machinery for its own sake — it exists so "what did we decide about X" has an answer with an address.

📄 4.2 The page family

✏️ 4.3 The sentence family

⚖️ 4.4 The working words

decision · standing · spine / close · sync · managed span · Skills row — six words, each naming one thing.

A coined word is a defect: every entry is the source documents' own word, and every entry names the page or file that defines it.

This is the absorbed glossary — QA1's substance carried whole, with its history left to the archive. The rule to stress is the defect rule: the glossary never invents, it only collects, so it can never become a second source that contradicts the pages.

§5 · The three folders

The ground: three folders, three kinds of truth

⚙️ ① skills/board/

SHIPS — read by a runtime. The family the whole world uses; only graduated Law lives here.

🗂 ② this board folder

ARGUED — read by people. Where decisions are made and kept; what is argued is kept.

📤 ③ every board/ site

RENDERED — read by anyone. Generated on every build; what is generated is disposable.

This board's subject IS the board — a board used to define boards — so a reader meets each idea twice: as this board's practice, and as the shipped contract. §5 keeps the two from being confused.

This is the absorbed folder map, formerly QA0. The self-reference is the trap to defuse out loud: when someone asks "which rule applies to me," the answer is always the shipped folder, never this board's own working practice — the two look alike by design.
