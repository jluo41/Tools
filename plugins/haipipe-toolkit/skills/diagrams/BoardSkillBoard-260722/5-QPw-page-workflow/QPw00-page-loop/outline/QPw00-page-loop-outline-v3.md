**Why v3 and not an edit of v2.** v2 was approved on 260819 and then the loop it
DESCRIBES changed underneath it, in the PREPARE loop this page now argues for. A
tick belongs to the version it ticked (`haipipe-page-outline` 0.3.0), so evidence
that moves the loop makes a new version rather than a quiet edit. All three stale
`serves:` addresses on 260819 came from editing v2 after its tick.

**What the evidence changed, and it is the loop's own shape:**

```text
  v2 planned      ① OUTLINE → ② DRAFT → ③ PROBE → ④ EVIDENCE → ⑤ REVISE

  the loop now    ┌ ① OUTLINE ⇄ ② PROBE ⇄ ③ EVIDENCE ┐   PREPARE, converges
                  └──────────┬───────────────────┘
                             ▼  ④ DRAFT → ⑤ REVISE → ⑦ CHECK
```

Two rulings did it, one day apart, and the second only worked because of the
first. The Aims moved into this file, which killed the single argument keeping
PROBE after DRAFT: a card's stake is an Aim, and Aims were written at DRAFT.
`haipipe-page-probe`'s MATCH-runs-late defect closed the same day.

**The four self-consistency checks pass on this plan** (`haipipe-page-outline`
§🚦): coverage, address, value, shape. What is left for a person is the one
question no file answers, which is whether the plan is aimed at the right thing.
