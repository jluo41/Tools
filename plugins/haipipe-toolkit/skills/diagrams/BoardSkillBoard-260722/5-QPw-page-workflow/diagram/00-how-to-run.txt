--S Your job is to BREAK, not to approve (JL ruled 260818) ----------

  the test for any proposed rule:
     can it be written down ONCE and never re-judged?
         YES  ->  AGENT.  add it to approve-rules/<kind>-rules.md
         NO   ->  YOU.    it is a break, not a rule

  AGENT rule                    HUMAN break
  --------------------------    ------------------------------------
  LOCAL: this axis label,       WHOLE: only visible looking at all
  this DOI, this button         of it at once
  right answer, independent     depends on what you WANT it to be
  of intent
  output: a VERDICT             output: a PROPOSAL, do it differently

  measured on 260818: the agent found 7 rule failures, 3 of them real
  content bugs in shipped files, 1 of them FALSE MATHEMATICS printing
  in the page PDF. It asked JL 2 questions all day.


--S The five ticks, and who writes them now -------------------------

  tick            on what                       who
  ------------------------------------------------------------------
  approved:       outline/<stem>-outline-v<N>   YOU, optional blanket
  verified        each bibex/<stem>.bib entry   agent, cite-rules R1-R7
  read:           each probe/PP<NN>/card.md     agent, value-rules R1-R8
  accepted:       each display/<unit>/README    agent, display-rules R1-R14
  the RULING      the Page Type's gate          YOU ONLY. no rules file.

  TWO go BACKWARD when their inputs change:  read:   accepted:
  the agent signs `auto`, never your name.

--S If something goes wrong -----------------------------------------

  "missing required raw-material packet field"
      -> the packet went in as a 2nd positional arg. it belongs in
         the args FIELD:  Workflow({scriptPath: "...", args: {...}})

  it loops REVISE and never closes
      -> the page has mechanical ERRORS of its own:
         cli/check.py <board> | grep '^<page-file>.md'
         board-wide errors do NOT count. page-scoped only.

  audit says source-artifact-missing
      -> fixed 260818. it now says page-path-stale and audits the
         file it found, because the page MOVED, it did not vanish.

  audit says checked-version-mismatch          <- OPEN BUG 260818
      -> CHECK left three disagreeing version ids
         (version_before / version_after / checked_version).
         Surfaced by run 260818-1543-QPw00 receipt[2]. Not yet fixed.
