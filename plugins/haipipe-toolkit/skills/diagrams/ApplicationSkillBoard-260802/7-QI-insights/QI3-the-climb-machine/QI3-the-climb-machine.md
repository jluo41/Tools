## Opening

Which rung does a question climb next, and when does a subgroup deserve its own ladder?

A phase machine answers both, and its phases are the lane's own six page types: I0 Meta, I1 Question, I2 Data, I3 Information, I4 Knowledge, I5 Wisdom, with gates GI0-GI6. The frontier's atomic unit is one register CELL, a question crossed with a partition, so phases climb the rows while partitions widen the columns, and two mechanical tests at the doors decide what may be a column and what may be a partition.

### Writing Style

Every law here is a test a reader could run. State the test's inputs before its verdict, and route every failure somewhere instead of discarding it.

## Content

### 1 · The phases are the rungs

**The naming law, satisfied rung by rung**: a journey phase is named by its authority page, and this lane owns exactly six page types, so the ladder itself is the phase spine. Two positions failed the test and became gates: the pooling verdict rides on an ordinary K page in X, so it is GI4's partition-major clause, and settle is a register act, so it is GI6. Each phase performs one epistemic operation, and each gate is an authority transfer: passing GI<n> is the moment the rung below becomes citable.

#### 2 · The cell frontier

Phase is read per question AND per partition. The same question may be answered on F, partial on B and open on D at once, so the board has no one-number phase and the machine refuses to mint one. The register matrix, read whole, is the frontier map, and the application machine's `🔎P0-P2` reading derives from the same cells.

#### 3 · The two tests at the doors

```text
partition test · I0    a cut may become a COLUMN SET only on three yeses:
                       disjoint+stable over the window · exogenous to the design ·
                       addressable as its own DS page (audience × job × venue)
routing test · I1      a question needing rows from ONE partition group is a
                       column question; from TWO OR MORE, an X question with
                       dot cells, answerable only in the X group
```

A partition is an AUDIENCE stratum: the insight lane's columns mirror the design lane's DS-page audience axis, because the pooling verdict splits COUNSEL and counsel is per-audience. A dimension that could never become an audience can never split the counsel, so making it a partition buys mirrors nobody will consume.

#### 4 · Time never needs the partition axis

The canonical failing candidate, wearing three guises with three existing homes:

```text
time as send-knob    fails exogeneity · the ARM axis: an I column, a design bet
time as pattern      an I column, engagement over the window
time as epoch        a new window is a NEW EXTRACT, hence a new board, with
                     MT00's freshness rule owning the seam
```

#### 5 · The instrument shadow

Both tests have a mechanical echo in the task layer. A column question runs the SAME task folder once per partition config, and one call may produce every column's numbers at once; a partition is a config and never a code change, so a subgroup needing different code disproves the partition or the topic; an X question gets its own folder reading the siblings' outputs; a new extract re-runs the same folders under a new source config. The task folder holds the convergent reasoning and the page holds the divergent reading: computation is reused, interpretation never is.

#### 6 · Refusal is convergence, and the machine is content-free

A 🚫 with a reason is a terminal state equal in rank to ✅: a board rich in refusal reasons is converging, not failing, and the defect is the cell that can neither answer nor refuse. And nothing in the machine names SMS: domain enters only at the extract, the questions and the venue packs, so substituting all three re-instantiates the whole machine on a wearable stream or a claims table unchanged.
