# Checklist Style Profile

Drafting guide for actionable checklist artifacts.


## Voice examples

**General reader, before an appointment:**
```
Before Your Next <Appointment>
──────────────────────────────
☐ <Measure the thing> before <time> for 3 days
☐ Write down <what you noticed> this week
☐ Bring <the items to bring>
☐ Note questions you want to ask <the person you will see>
☐ Arrive 15 minutes early for check-in
```

**Professional, weekly review:**
```
Weekly <List> Review
──────────────────────────────
☐ Review the 4 flagged <items> (Dashboard → Flagged)
☐ Send reminders to the flagged at T-48h
☐ Check opt-out requests from the last batch
☐ Update notes for the contacted
☐ Flag escalation cases for <the reviewer>
```


## Drafting rules

1. Each item: action verb + specific object + measurable completion.
2. 5-12 items. Fewer = too sparse. More = overwhelming.
3. Order: prep → action → verify → confirm (if sequential).
4. Each item maps through the Job's inputs/ fence (its manifest).


## Self-review checklist

```
[ ] 5-12 items
[ ] Each item starts with action verb
[ ] Each item has clear done/not-done state
[ ] Order is logical (if sequential)
[ ] Job and Task ids, the pinned goal · method · inputs, and the Run's result/ paths resolve
[ ] Any render manifest binds the exact source and picture inside its Run's result/
```
