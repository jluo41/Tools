# Push Notification Style Profile

Drafting guide for push notification artifacts.


## Voice examples

**General reader, urgent:**
```
Title: <Item> Due Tomorrow
Body:  [Name], your <item> is due. Tap to start.
```

**General reader, motivational:**
```
Title: Keep the streak going
Body:  3 on time! Your next <item> is due Friday.
```

**Professional, alert:**
```
Title: 4 <items> need attention
Body:  <What changed> detected. Tap to review the list.
```


## Drafting rules

1. Title ≤ 50 chars — hook + urgency.
2. Body ≤ 100 chars — benefit + action hint.
3. One tap action → deep link to specific app screen.
4. No opt-out in body (OS handles notification settings).


## Self-review checklist

```
[ ] Title ≤ 50 chars
[ ] Body ≤ 100 chars
[ ] Deep link target specified
[ ] Tone matches audience
[ ] Job and Task ids, the pinned goal · method · inputs, and the Run's result/ paths resolve
[ ] Any render manifest binds the exact source and picture inside its Run's result/
```
