# haipipe-insight-evidence-plan · version history

## 0.4.0 · 2026-10-02 · Plan from the question layer (JL 261002)

- Plans from the whole question (short wording, name, why now, what would answer it), not from the ask alone; a question that already has needs keeps them, and other changes go to the question review. Coverage adds no need: an uncovered word or a cause word is a review note. The `**Ask covered**:` line and the `ask:` quotes are dropped; the blind-drafter rule holds for a question with no needs yet.

## 0.3.0 · 2026-10-02 · The question owns its run (JL 261002)

- The ask is read as phrases, each covered on an `**Ask covered**:` line; `measure:` and `by:` quote the ask; output files are named for the measure; the drafter writes the proposal without reading tasks. A causal verb in a Data or Information ask is reworded or routed to Knowledge.

## 0.2.0 · 2026-10-01 · Work specs and the page flow (JL 261001)

- Writes the work spec of every compute need (cut, unit, measure, by, uncertainty, rivals, output) from the ask alone, before any task is opened; a refusal is planned as a compute need for its probe.

## 0.1.0 · 2026-10-01 · First version (JL 261001)

- Plans one question's evidence needs (compute · cite · judge, with `pass:` and `from:`) on its register row, before any run, for a person to agree. The Insight workbench's "Plan the evidence" run. Contract: `haipipe-insight/ref/evidence-needs.md`.
