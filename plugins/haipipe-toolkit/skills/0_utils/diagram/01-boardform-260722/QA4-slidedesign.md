# Single-Q slide layout
state: 🟡 PARTIAL
owner: CC
method: 聚焦模式去掉卡片框，照 html-ppt 的幻灯片来排

## Question
点开一个 Q、屏上只剩它的时候，这一屏该长什么样？什么放大、什么收起、什么根本不该出现在台面上？

- [x] 翻到下一题不用回目录

## Now
已经做到的：
点目录任意一行进入聚焦，纯 CSS（`:target` + `:has()`），零脚本。
卡片框在聚焦时去掉了 —— 不再是页面上的一个盒子，而是内容直接铺开。
标题、问句、正文在聚焦时统一放大，正文加宽到 1000px。
「现在什么样」和「到什么程度算做完」左右并排，借的是 html-ppt 的 `comparison.html`。
顶上留一条细的跑马条：板名 + 主干 + 两个全局入口（🦴 这块板在干嘛 / 🔄 这些 Q 是怎么排的），折叠着，任何一题上都点得到。
底部一行 `← 上一题 · ☰ 全部 · 下一题 →`。

还没定的：
标题多大算合适（现在 38px），一屏塞不下的长题怎么办 —— 截断、滚动，还是拆成两屏。
要不要像 html-ppt 那样锁 16:9，还是随窗口高度走（现在是后者）。
「讨论」和「名词」两个折叠块，在幻灯片上算不算噪声 —— html-ppt 的规矩是讲者的话一律进 `notes`，不上台面。
方向键翻页要 JS，board.html 现在坚持零脚本，这条跟 QA3 是同一个口。

## Why here
QA3 管的是「另出一份 deck.html 拿去投屏」，这一题管的是「board.html 自己的聚焦模式」—— 两件事，容易混。
而且这是最影响「一眼能不能看懂」的一题：同样的文字，排成一个带框的小卡片，和排成一张不带框的幻灯片，读起来完全是两回事。

## Glossary
不带框（unbounded）：不再用边框、圆角、卡片底色把内容围起来，让它直接铺在页面上 —— html-ppt 的幻灯片就是这么排的。
跑马条：聚焦时顶上那一条压扁的头部，只占约 110px，保证不管翻到哪一题都还知道这块板在干嘛。
