🦴 Topic —— 这块板在干嘛

board（板）是干什么用的：一个话题下面有几个还没定的问题，把它们摊在一页上，谁都能打开看、能在上面写评论；问题一个个定完，这块板就关掉。

人物：JL = 拍板的人。CC = Claude Code，干活的。RA = 研究助手，将来会被指派一块板做几天。

这块板特殊在：它讨论的就是「板」这个东西本身 —— 用一块板来定义板。

🔄 Pipeline —— 这些 Q 怎么排

十个 Q 分三组，编号里的字母就是组：QA 定形状、QB 交出去、QC 等 JL 拍板。

QA1–QA6 先把「一块板」这个东西本身定下来：文件夹形状 → 一个 Q 文件的模板 → 投屏怎么办 → 单题那一屏怎么排 → 正文怎么写才是人话 → 怎么在上面加行内评论。这六个不定，后面全悬着。
