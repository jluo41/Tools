# Q file template
state: 🔴 OPEN
owner: CC
method: 定一份可以直接复制的空模板，标清楚哪些必填

## Question
打开一个空的 `QA5-xxx.md`，我该往里面填什么？哪些段落是必须有的，哪些可以不写？

## Diagram
```
QA5-xxx.md                              显示在哪
┌──────────────────────────────┐
│ # 短标题          ≤14 字      │ →  索引一行 + 幻灯片大标题
│ state: 🔴 OPEN               │ →  状态徽章
│ owner: CC   method: …        │ →  卡片头那一行
├──────────────────────────────┤
│ ## Question                  │ →  ❓ 最显眼那行
│ ## Diagram   ascii 图        │ →  问句下面
│ ## Now                       │ →  上
│ ## Done when - [ ] 勾选清单   │ →  下（自动数出 2/5）
│ ## Why here                  │
│ ## Glossary ## Discussion    │ →  折叠，不上台面
└──────────────────────────────┘
```

## Done when
- [ ] `ref/` 下有一份能直接复制的空模板文件
- [ ] 每个段落上面一行注释：这儿写什么、写多长
- [ ] 标明哪些必填、哪些选填
- [ ] 新加一题＝复制模板改文件名，不用参考任何已有的板

## Why here
QA1 定的是文件夹，这一题定的是**一个文件内部**。这是 RA 和以后的 agent 真正每天要动的那个东西 —— 模板不清楚，每个人写出来的 Q 都不一样，页面就乱。
而且模板直接决定页面上能显示什么：生成器只认这几个固定段落名，写了别的名字就不显示。

## Now
格式在跑，但只存在于「现有几个文件长这样」，没有一份模板，也没写下哪些必填。目前实际用的是：

```
# 短标题            必填 · 一个短语，≤14 字，像幻灯片的标题；完整问句写进 ## Question
state: 🔴 OPEN          必填 · ✅ SETTLED / 🟡 PARTIAL / 🔴 OPEN / ⏸️ ON HOLD
owner: CC               必填 · JL 显示成 🧠 拍板，其他显示成 🔧
method: 一句话说怎么做   选填 · 显示在卡片头一行

## Question    必填 · 一句真正的问句，页面上是最显眼那行
## Done when   必填 · 勾选清单，一条一行：- [ ] xxx / - [x] 已经做到的
## Now         必填 · 现在的实际状态，有数字给数字
## Why here    必填 · 不写就没人知道这题为什么值得占一页
## Glossary    选填 · 折叠 · 这一页出现的、外人看不懂的词
## Discussion  选填 · 折叠 · 评论写这里，一行一条：> JL: …  /  >> CC0722: …
## Log         选填 · 折叠 · 这题改过什么，一行一条：260722 · 改了什么
```

已经定下来的两条（JL 当场提的）：
标题必须是短语，不是句子 —— 完整问句归 `## Question`。八个 Q 的标题已经从最长 43 字压到 8–15 字。
`## Done when` 一律写成勾选清单，页面上会自动数出 `2/5` 这样的进度。

还没定的：段落顺序能不能乱；`## Glossary` 是不是每题都要；`state` 后面还能不能跟自定义字样。

## Glossary
必填：缺了就算这个 Q 文件不合格。生成器不会报错，但页面上会缺一块。
