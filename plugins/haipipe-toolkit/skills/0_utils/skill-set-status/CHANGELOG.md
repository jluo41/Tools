============================

Skill-scoped changelog (never loaded at invocation; read on demand). Versions
match SKILL.md frontmatter `version:`. Newest first.

**v0-series rule:** inherited from `haipipe-board`; this skill stays on `0.x.x`
and never reaches `1.0.0` without JL's explicit say-so.

- Renamed `haipipe-skillset-status` to `skill-set-status`: folder, frontmatter
  name, invocation trigger, title, and active cross-references now use the new
  canonical id. Historical changelog entries retain the names current when
  those entries were written.

## 0.3.0 — 2026-08-28

- SIZE joins every class table (JL: "也需要说一下它总共有多少个字…够不够简洁"):
  each row carries `<SKILL.md chars>/<desc chars>` — the invocation load and

## 0.2.0 — 2026-08-28

- **Five classes, five tables, each with its own columns** (JL 260828: "每个表
  里,每一行代表一个 skill · 每一类表有不同的 column"), and RENAMED
  `haipipe-pagetype-quality-check` → `haipipe-skillset-status`: the old name
  described one of the five tables and would have been a property-② failure
  under its own ruler once it began scoring doors and banks.
- New class rulers: **DOOR** (routes / resolve / stale / scaffold / desc
  shape), **MACHINE** (phases / gates / receipt owner / fired live / gazette),
  **LIBRARY** (count / neutral / clock / consumed at / oldest verify),
  **CRAFT** (lives in / scope / reversible). The eight-property page-type
  ruler survives unchanged as the CONTRACT class.
- Classification is by what a skill OWNS, not where it sits, so a craft stored
  in a sibling folder is still counted as a family member.
- The provisional law generalizes from CONTRACT to every class: a row with an
  empty field record is `(provisional)` whatever its static score.
- New `§ Where the result lives`: the instrument stays in this skill, the
  result goes to the family's `README.md § Family status` with an `as of` date
  and the regenerate command. Dated table = receipt; undated table = a second
  authority that rots. The Roadmap's Intake law applied to the skills.
- The procedure gains step 4, the mechanical-facts gather: versions, routes,
  instances, gates fired and assets each come from a named command rather than
  recollection.
- The worked example is the paper family's 260828 five-table run. Its two
  knife points are exactly what one table could not see: the DOOR carries no
  `version:`, and only 4 of 8 gates have ever fired.

## 0.1.0 — 2026-08-28

- **Created on JL's 260828 ask** for a way to measure Page Type contract
  quality with a total score: eight static properties read off the contract
  text (grain-law-why, borrowed-words, address-grammar, size-before-release,
  per-field-law, receipt-duty, grep-able-checks, explicit-non-jobs) scored
  ✓/◐/✗/—, four dynamic counters read off the boards and git (instances,
  fieldtest gaps, CHECK first-pass, post-close repairs), and a total written
  `<static> · <tier>`.
- **The provisional law**: an UNTESTED contract (zero instances) is written
  `(provisional)` whatever its static score, so polish is never mistaken for
  proof. Founding counterexample: the paper family's round contract, complete
  on paper and never once instantiated.
- Scoring from memory declared a defect; every ✗ or ◐ must name the missing
  thing and every ✓ must point at the line that earns it.
