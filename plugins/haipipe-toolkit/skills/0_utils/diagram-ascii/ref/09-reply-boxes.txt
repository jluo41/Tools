OPTIONAL REPLY BLOCKS — for unusually operational handoffs
==========================================================
Ruled 260818, in two corrections one after the other:
  "I want the style like this, highlight your answer, highlight
   what I need to do."
  "I think you should also highlight your quick answer."
This was the default through v0.3.0. JL retired that universal format on
260907. Natural prose is now the default; these blocks remain available only
when explicitly requested or when a consequential user action would otherwise
be hard to find.


--S Optional shape --------------------------------------------------

RULES ONLY: a line above and a line below. NO left or right edge.
Ruled 260819: "你这个 box 能不能只保留上下，不要左右，然后把它变得越宽越好？"
Side pipes force every line to be padded to one width, which caps the
text at about 58 columns and wraps sentences that would otherwise fit.

══════════════════════════════════════════════════════════════════════════════
✅ ANSWER · <the answer to what was asked, one line>
<at most 2 more lines: the number, the path, the verdict>
══════════════════════════════════════════════════════════════════════════════

══════════════════════════════════════════════════════════════════════════════
🧑 YOURS · <how long, or the word "nothing">
<the literal thing to type, click, or decide>
<what happens if it is skipped>
══════════════════════════════════════════════════════════════════════════════

<continue in ordinary prose; add a diagram only when it clarifies the answer>


--S Current rules ----------------------------------------------------

1. Do not use these blocks by default.
2. If the user explicitly rejects the format, do not use it.
3. When a YOURS block is useful, it holds the literal decision, command, or
   path—not a vague description.
4. Use only the blocks that add value; MINE and time estimates are optional.
5. Rules are 78 columns, with no side edges or padding.


--S Worked optional example -----------------------------------------

✅ ANSWER · Yes. Rules only from now on, 78 columns, no side pipes.

--S Default: skip the blocks -----------------------------------------

- ordinary factual answers
- discussion and brainstorming
- status updates and handoffs with no consequential user action
- a pure "sketch this" request, where the diagram itself is the answer
- whenever the user asks for another format
