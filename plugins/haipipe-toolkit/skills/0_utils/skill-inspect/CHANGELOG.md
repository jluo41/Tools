# CHANGELOG · skill-inspect

## 0.1.0 · 2026-08-31

Born from JL's ask ("inspect the skill set, and return with the expected
structure, outline — what are the skills, what are the folders to create,
what is the current status"). Four-section report (skills · expected
structure · status vs --target · gaps), read-only, structure read from each
family's declaration file (roster.md, task-structure.md, pagetypes.py), never
from a live example. Boundary set against skill-set-status (quality) and
field-test (cold run).
