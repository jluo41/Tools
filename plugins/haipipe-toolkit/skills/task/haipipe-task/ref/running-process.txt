The suffix is always results/<task>/<run>/ or notebooks/<task>/<run>.ipynb.


TICKET FLOW
===========

1. Validate bNN/jNN/tNN/rNN path and same-stem Page.
2. Resolve config, worker, output root, and execution address.
3. Check CODE_REVIEW.md against the current git SHA.
4. Write runtime.yaml with status running before expensive work.
5. Convert the # %% worker to a generated notebook template.
6. Execute with papermill and inject the exact Run config.
7. Check required Result paths and the worker-specific Result gate.
8. Atomically write the terminal receipt.
9. Hand off to `/haipipe-task report <task-folder>`.
