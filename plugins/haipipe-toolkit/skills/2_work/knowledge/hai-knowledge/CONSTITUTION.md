## A11 · A Page tab leads with one line, then one item per line, each with its emoji

> for the page part, how to add more bullet points and emojis to make it more vivid to read?

**Source:** user request on b18 s11's Page, 2026-11-27; same trace as A08.

**Rule:** Each Page tab starts with one bold sentence that answers it. Under it, one item per line in a list, never
a paragraph that hides several items. Each item starts with an emoji that says what kind of item it is, the same
emoji for the same meaning across the Block:

| Emoji | Means |
|---|---|
| 🆕 🧱 🔢 🗑️ | opens, lays out, sets a value, removes |
| 👆 📤 📥 🏠 | a user action, sent to the server, received, stays on the device |
| ✏️ 🧰 📂 | what to change, which tool, where it is in the example |
| 💡 ⚠️ ✅ ❌ | the key idea, a boundary, it shows, it does not show |
| 📖 🔗 | what to read, who uses it |

A method step or a source ends with `🔍 **Look for:**` (where to see it in a Resource or a picture) and
`✅ **You know it when:**` (how the learner checks themself). Tables keep an emoji in each header cell. Code blocks
and official pictures stay as A08 and A09 say.

**Check:** by eye on each Page tab: a bold first line, a list instead of paragraphs, one emoji per item with the
meanings above.
