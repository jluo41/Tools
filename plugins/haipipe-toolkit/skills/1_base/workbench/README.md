# workbench · the family map

The shared screen manuals, in one folder (JL 261016, s21-D05); moved out of `../draft/` on 2026-10-16. The screens'
code is in `servers/` (`servers/workbench/`, `servers/_host/`); these skills say what each screen shows, what it
stores and who writes it. A theme's own screen manual (`2_work/<theme>/workbench-<theme>` or `3_theme/<theme>/workbench-<theme>`) stays with its theme, and a Task type's with its family (the draft Task's: `../draft/workbench-task-draft/`); and
the Studio screen is `../project/hai-studio/ref/screen.md`.

```
hai-workbench/         🔌 the /wb door and the WORKBENCH contract: open a place by path or words, ref/roster.md (the folder roster)
hai-lab/               🧪 the /hai-lab door: a paper, insight, design or labeling Block as VS Code windows of its sessions (cli/lab.py)
hai-ui/            👁 the rules every page passes (five-second test, one verb per section) and the blind page review
hai-interaction/   📝 request and record the input a page's work needs: question forms, answers pasted back; one Interaction button on the workbench rows (scripts/collect.py)
```

Start at `hai-workbench/SKILL.md` (`/wb`). The Page agents (`hai-draft-*-agent`) live in `../draft/hai-draft/agents/`.
