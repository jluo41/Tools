# glossy-cartoon

Bright glossy 3D cartoon panels with lettered options and a ribboned favourite

## Design Aesthetic

A polished explainer page: rounded option panels side by side, each holding one glossy 3D cartoon object (folders,
chips, robots, people), a letter badge on each panel, and the favoured option boxed with a ribbon. Confident and
finished, like a product launch slide.

## Background

- Color: Pure White (#FFFFFF)
- Texture: none; soft gradients inside the panels

## Typography

### Primary Font (Headlines)

Heavy rounded sans-serif, near-black navy, large and centred; a coloured subtitle line under it.

### Secondary Font (Body)

Bold clean sans-serif captions under each panel.

## Color Palette

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Background | White | #FFFFFF | Page |
| Primary Text | Navy | #0B1F4D | Title, the takeaway line |
| Subtitle | Royal Blue | #1D4ED8 | Subtitle |
| Panel 1 | Lavender | #EDE4FF | Option A panel, purple badge |
| Panel 2 | Sky | #E0F2FE | Option B panel, blue badge |
| Panel 3 | Mint | #DDF7EE | Option C panel, teal badge |
| Warning | Amber | #F59E0B | The "Still open" line and its icon |

## Visual Elements

- Glossy 3D cartoon objects with soft shading and highlights
- Round letter badges A, B, C at each panel's top-left
- The favoured panel framed in navy with a small "LEANING" ribbon
- One navy takeaway line and one amber "Still open" line at the bottom

## Density Guidelines

- Three panels, one caption each, one takeaway line, one open line

## Style Rules

### Do

- Keep the panels the same size and evenly spaced
- Put the favourite last and frame it

### Don't

- Add slide numbers, footers or logos
- Use more than three panels

## Best For

Launch-style summaries of a settled choice. Not for a Studio: it reads finished, like a report (JL 261029).
