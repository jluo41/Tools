# Base prompt: the shell every slide picture shares

The words below go first in every slide's image prompt, before the style and the slide's own content. A style never
overrides them.

<!-- BASE -->
Create one presentation slide as a single finished picture.

Image: 16:9 landscape, about 1920x1080. One clear message.
Everything is drawn in the style below; no photographs, no realistic people.
No slide numbers, page numbers, headers, footers or logos.
Use exactly the text given under SLIDE CONTENT, spelled exactly, in English; add no other words.
At most four groups of text. The headline is the largest and is read first.
Generous margins and white space; one focal point draws the eye first.
Add none of these words on your own: "dive into", "explore", "journey", "let's", "exciting"; write them only where SLIDE CONTENT quotes them.
Never write a headline as a contrast ("X is A, not B", "not X but Y"); ask the question plainly or name the options.
<!-- BASE -->

## What the slide's own content must give

A headline that says the point ("A Block is a promise to one reader?"), not a topic label ("Block definitions"); each
group of text and what is drawn with it; where things sit; which one is the focal point. See `content-rules.md`.
