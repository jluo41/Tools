# Requirements of a Method topic

The class of every topic in a Knowledge Block's Method band (s1N and s2N); s05 Block Structure: Knowledge names it. The band is the type: every topic in it has these top
buttons and left tabs. `## ` is a top button, `### ` a left tab under it; the type's right side shows the
requirement, a topic's right side shows its real page. Try explaining, Draw, Map and Slides come from the base
type; this file writes only the type's own Page tabs.

base: plugins/haipipe-toolkit/skills/1_base/project/hai-studio/base-types/learning
instances: article[id="s11-messages-components-data"],article[id="s21-tracing-interaction"],article[id="s22-chatbot-to-a2ui"]

## Page

### Where you start
what: The situation the steps start from, and what the learner already has.
why: A step only makes sense from a known starting point.
from: the `## Where you start` section
must:
- the first left tab
- one concrete example the steps follow
check: by eye: every step below uses this example

### 〈n〉. 〈step〉
what: One step: what to do or look at, and what it shows.
why: A learner can stop after any step and check it.
from: one `## 〈n〉. 〈step〉` section
must:
- numbered from 1, in order, named by what the step does
- one action or one thing to look at per step
- a source link where the step states how A2UI behaves
- ends with `🔍 **Look for:**` (where to see it in a Resource or a picture) and `✅ **You know it when:**` (how the learner checks themself)
check: by eye: the steps read in order without skipping
