Method
======

1 · The six steps
-----------------

| step | what happens | methods | where in the workbench | who signs |
|---|---|---|---|---|
| Frame the question | name the question worth asking and why it is not yet answered | Framing | Ideation › Ideas · runs Generate ideas, Test idea, Idea review, Select idea | the admitted idea (G0) |
| Write the Story | the contribution, and one claim per question with its warrant | Story | Story › Spine · RoadMap Draw · Related Papers · runs Story revise, Redraw, Discovery runs | the Story version |
| Fix the evidence, then the work | each question's evidence named before its Task work runs; a report answers it | Story | Story › High-level logic + Low-level work · runs Task runs, Task review, Write the report, Review the report, Claim review | the Task work (G1), the answer (G2) |
| Write the Sections | each Section Page tells part of the Story, in the reader's order | Writing and response | Sections › Table · Evidence · Narrative · each Section opens the Page workbench · runs Draft runs, Evidence runs, Delivery runs, Page check, Narrative review | one Section (G3) |
| Deliver | assemble the paper, check it, write the cover letter | Writing and response | Delivery › Preview · Artifacts · Checks · Cover letter · runs Build, Check, Cover letter | submission (G4) |
| Answer the rounds | quote, answer and change the paper for every reviewer point | Writing and response | Delivery › Rounds · run Response | every response (G5) |

A reviewer's point goes back to the step it is about: a claim to Write the Story, a
missing analysis to the work, an unclear passage to its Section. A gate is closed by a
person, never by a passing test. Every run is in the Runs panel beside its Space, with the
prompt to start it.

One example runs through this page, and it is made up: a paper that asks whether a
reminder text raises prescription refills, and for whom.

The steps happen in four Spaces of the workbench, each with its own Views:

| space | what it is for | view | what it shows |
|---|---|---|---|
| Ideation | choose the one question the paper will answer | Ideas | every candidate idea with its tests and reviews; the one a person admits becomes the paper's question |
| Story | plan the paper: its questions, claims and the evidence each needs | Spine | the contribution in one sentence, then each question with its hypothesis and claim, in the order the paper tells them |
| Story | | RoadMap Draw | the Story drawn on a canvas you edit; the drawing is kept with the Story |
| Story | | High-level logic + Low-level work | one row per question: its Logic (what would answer it), the Task Work that runs, the Report that answers it |
| Story | | Related Papers | the papers each claim leans on, one card per paper, found by Discovery runs |
| Sections | write each Section as a Page, in the reader's order | Main · Appendix | two tabs: the Section Pages of the main text, and of the appendix |
| Sections | | Table | each Section with its draft version and state; a row opens that Section's Page workbench |
| Sections | | Narrative | the Sections read in order, to check the Story flows from one to the next |
| Sections | | Evidence | each Section's values, citations and displays, and whether each is bound to its Result |
| Delivery | assemble, check and submit the paper, then answer the reviews | LaTeX · Word | two tabs: the assembled paper in each format |
| Delivery | | Preview | the paper as a reader will see it |
| Delivery | | Artifacts | the built files: the .tex, the .docx, the PDF and their figures |
| Delivery | | Checks | the whole-paper checks before submission |
| Delivery | | Cover letter | the letter to the editor, its files and its checks |
| Delivery | | Rounds | each review round: the reviews, the response, and the changes made |


2 · Step 1 in depth: framing the question
-----------------------------------------

Before any work is planned, the paper picks one question and says what kind of
contribution answering it makes. In the example the question is "does a reminder raise
refills, and for whom?", and the contribution in one sentence is "a reminder text raises
refills, most for people who have missed one before".

| family | method | card |
|---|---|---|
| Framing: Which question is worth asking? | By problematization | methods/framing/01-by-problematization.md |
| Framing: Which question is worth asking? | By one main idea | methods/framing/02-by-one-main-idea.md |

This step has no test of its own: an Idea review by an agent that did not generate the idea
comes first, then a person admits one idea (G0).


3 · Steps 2 and 3 in depth: claims and their evidence
-----------------------------------------------------

Each claim names the evidence that grounds it and the warrant: why that evidence supports
it. A qualifier and a rebuttal say where the claim stops.

```
evidence    refills rose 41% → 44% in the reminder arm          (made up)
   │  warrant: the arms were randomized, so the gap is the text's
   ▼
claim       a reminder raises refills
            qualifier: for adults on monthly refills
            rebuttal: unless the gap is gone at 90 days
```

Each question then keeps one row across Logic, Work and Report: what would answer it,
written first; the Task Runs that produce it; the report that answers it from exact
Results.

```
Logic                         Work                         Report
Q2 · for whom most?      →    Task Runs write Results  →   the answer, with its
test the difference,          with receipts                evidence, limits, next
named before any run
```

| family | method | card |
|---|---|---|
| Story: What do we claim, on what evidence? | By claim and warrant | methods/story/01-by-claim-and-warrant.md |
| Story: What do we claim, on what evidence? | By evidence before claims | methods/story/02-by-evidence-before-claims.md |
| Story: What do we claim, on what evidence? | By reproducible run | methods/story/03-by-reproducible-run.md |

| test | asks | when | source |
|---|---|---|---|
| T0 Asked | every claim answers one Story question | step 2 | one main idea per paper (Mensh & Kording 2017) |
| T1 Warranted | every claim names its evidence and why it supports it | step 2 | claim, grounds and warrant (Toulmin 2003) |
| T2 Fixed first | each question's evidence is named before its Task work runs | step 3 | review before results (Chambers & Tzavella 2022) |
| T3 Reproduced | each evidence item comes from a recorded Run with its receipt | step 3 | reproducible computation (Sandve et al. 2013) |

In the example, T2 fails if the test for "past missers" was chosen after the refill data
were read.


4 · Steps 4 and 6 in depth: telling and defending
-------------------------------------------------

The Sections tell the Story in the order a reader needs it: in the example, the Results
Section tells Q1 before Q2. Each Section is a Page, written and checked by the Page
workbench's method. Step 5, Deliver, has no method of its own: it assembles the checked
Sections and checks the whole paper (G4). When the reviews come back, every point is
quoted, answered and routed to the step that owns it.

| family | method | card |
|---|---|---|
| Writing and response: How is it told, and defended? | By reader expectations | methods/writing/01-by-reader-expectations.md |
| Writing and response: How is it told, and defended? | By point-by-point response | methods/writing/02-by-point-by-point-response.md |

| test | asks | when | source |
|---|---|---|---|
| T4 Independent | an agent that did not write a Section checks it | step 4 | the Page method's T4 (ours) |
| T5 Answered | every reviewer point is quoted and answered, and the paper changed for it | step 6 | responses to reviewers (Noble 2017) |


5 · Why it works
----------------

A paper makes one contribution
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

A paper says one new thing, and every part of it serves that thing (一篇论文只做一个贡献).

```
contribution   reminders raise refills, most for past missers
   ↑
questions      Q1 does a reminder raise refills?   Q2 for whom most?
   ↑
claims         one claim answers each question
```

The evidence is named before the work that produces it runs, so the answer cannot shape
the question it answers.

What the evidence says
~~~~~~~~~~~~~~~~~~~~~~

- Fixing the plan first changes what is found: large heart, lung and blood trials that
  showed a benefit fell from 17 of 30 to 2 of 25 once outcomes had to be registered first
  (Kaplan & Irvin 2015); Registered Reports had 44% positive first hypotheses against 96%
  in standard reports (Scheel et al. 2021).
- Most research questions are built by spotting a gap in earlier work rather than by
  challenging the assumptions under it (Sandberg & Alvesson 2011).
- No study tests this loop on agent-assisted papers; its order is our own judgment.

Where a paper sits
~~~~~~~~~~~~~~~~~~

```
💡 Ideation   candidate ideas → one admitted question
      ↓
🧭 Story      questions → claims → the evidence each needs → Task work → reports
      ↓
📄 Sections   one Page per Section, in the order a reader needs them
      ↓
📦 Delivery   the assembled paper, its checks, the cover letter, each review round
```

No Section states a claim the Story does not hold, and no claim stands without the report
that answers its question (ours). The papers behind each method are listed in Related
Paper.
