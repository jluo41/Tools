## 0.2.0 · 2026-09-22

- The direct door: the person edits Draft sentences in Draft Space → Revise; each Save is one
  Step of `rp-revise-NN_<C.P>` with one card per changed sentence, Decision `accept`. The compare
  door (two frozen texts) is unchanged. `ref/change-ledger.md` documents the direct-edit Step.

## 0.1.0 · 2026-09-22

- New skill: the Revise Run (`rp-revise-NN_<target>`), asked for by JL: compare
  two frozen texts of one target and settle every change. The Result is a
  change ledger (`ref/change-ledger.md`) in the Step template's Track changes
  shape plus a Decision per row; the presenter renders it as red/green cards
  under Page Writing → Revise. The accepted text returns to the writing Run as
  a Version, so Revise owns decisions, never prose.
