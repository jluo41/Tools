## 0.1.0 — 2026-08-19

First contract, on JL's 260819 ruling: "probe 是一个大 folder，里面放了所有的
value，而有的时候我们在正文里面只会用到一个具体的 value... 我们是不是可以给
value 也单独分一个？"

- **A plugin with a SURFACE and no STORAGE.** The number already lives in a probe
  card's `proof/` with its source, run and sha256; a `<page>/value/` folder would
  be a second home for one thing, which is the rule that retired 🧮 proof the
  same day. What was missing was one more level of ADDRESS.
- The join runs both ways, and that is why it earns a plugin rather than a rule:
  🕳 a number in the prose citing no `PP<NN>.v<n>`, and 🎈 a value no sentence
  uses. Neither the 🚪 probe strip nor the 🧭 outline tab can see either.
- Precedent for storage-less on this board: `haipipe-plugin-outline` 0.1.0.
