# approve-rules · what a machine may pass, and what it may never judge

**The cut, ruled by JL on 260818.** A rule that survives being WRITTEN DOWN
belongs to an agent. A judgment that must be RE-MADE every time, because it
depends on what a person wants the thing to be, belongs to that person.

```text
                   🤖 AGENT rule              🧑 HUMAN break
scope              LOCAL: this axis label,    WHOLE: only visible looking
                   this DOI, this button      at all of it at once
right answer?      YES, independent of        NO, it depends on intent
                   what anyone wants
write it down?     ✅ survives, never needs   ❌ dies. tomorrow's answer may
                   judging again              differ with nothing on disk changed
output             a VERDICT, pass or fail    a PROPOSAL, "do it differently"
```

**The test to apply when a new rule is proposed:** can this be written so it
never needs judging again? If yes, add it to the matching file below. If it
must be re-judged, it is not a rule and writing it down would fake a judgment.
An agent asked "is this display good overall" answers confidently and is wrong,
which is worse than not asking.

## The four files

```text
approve-rules.md   🧭 an OUTLINE plan, before prose is written
display-rules.md   🖼 a DISPLAY unit, before it is accepted
cite-rules.md      📚 a BIBEX entry, before it is verified
value-rules.md     🔢 a PROBE card, before it is read
```

## How they grow

Every 🛑 a person writes is PROMOTED into the matching file as a new rule, in
that person's own words, so the same break never happens twice.

```text
🧑 🛑 JL · "B4 keeps #### 1.3. the uncertainty rule lives ONLY there."
            │
            ▼
✍️ approve-rules.md gains:
   R-<n> · Never delete the ONLY place a rule is written, even when the
           surrounding division is being shrunk.
           promoted 260818 from JL's break on QPw00-page-loop-outline-v1
```

A promoted rule keeps `promoted <date> from <whose break> on <what>`, because a
rule whose origin is lost is a rule nobody can argue with later.

## What a pass looks like

```text
<verb>: ✅ auto <YYMMDD> · rules <file> R1-R9 all pass
<verb>: ⬜ auto <YYMMDD> · R4 fails: <the exact rule text>
```

🛑 A person's mark OUTRANKS every agent pass beneath it, always, and needs no
rule to justify it. Silence is still never consent for the one tick that stays
human: the Page Type's RULING.
