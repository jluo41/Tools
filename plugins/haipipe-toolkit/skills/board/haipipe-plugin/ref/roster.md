# The plugin storage roster · one row per lane or category name

The single list of Page material names (design.excalidraw, JL 260815).
A subfolder of a Page's home folder is board material only if its name is here.
A row identifies storage, not necessarily a separate Plugin Skill: a category
Plugin may directly own one of its internal lanes.
`kind`: PRIMARY = originals a person makes, committed; DERIVED = projections of the page's text, regenerable, gitignorable.

**Evidence is one Plugin over four internal lanes:** Citation/Bib, Value,
Display, and PageX. Probe remains a separately governed crossing presented in
the same tab. The typed Evidence Item table
(`outline/<stem>-evidence-items.md`) is where SHAPE specifies the ready target
and SURVEY plans Supporting Runs, exact PageX bindings, one Local Input, and
one Local Run. PageX is source authority, never a Run, Result type, or Probe
answer.

Writers for the DERIVED document trio live in `skills/board/page-plugins/_shared-export/` (`md2tex.py`, `md2docx.py`, `docx2pdf.py`); the board calls them by path.
`--paper-root` is discovered by walking up from the page for a `0-*.bib`; a page outside any paper exports cite-less rather than refusing.
Per-plugin Skills ship under a contributing plugin's `skills/page-plugins/`:
draw · slide · chat · latex · word · probe · outline · skill · meeting ·
design · render · evidence · labeling. Citation/Bib, Value, Display, and PageX
have no separate Skills: `haipipe-plugin-evidence` owns their internal lanes.
The retired Task and Direction plugins have no active row. Labeling's skill
lives with the subjective-label family while its Board surface is loaded by
the shared Board engine.

Category and meta Plugins need not correspond one-to-one with storage rows.
`haipipe-plugin-folder` is the 📂 meta-surface over this list;
Evidence owns Citation/Bib, Value, Display, and PageX and presents separately
governed Probe beside them;
Delivery presents latex, word, slide, and render; Studio stages Draw and Chat;
and Runs joins Tickets to Results. Evidence does absorb its four lanes' writers
and gates; other category surfaces do not unless their contract says so.

Twice the plugin arrived before its name did, so the order remains: roster row first, then per-plugin skill.
