# `artifact` · author one independently reviewable delivery unit

1. Resolve the requested unit from the accepted Intervention component map. Ask only when several unstarted units match.
2. Create or resume one `page-type: artifact` Page and set `artifact-kind` plus stable `artifact-unit`.
3. Load the current Intervention handoff and venue pack. Reject a stale or missing handoff before writing content.
4. Keep variants reviewed together as Content divisions. Split units only when one can be accepted while another is rejected.
5. Build the venue-required preview with Page plugins. Record both handoff version and render version.
6. Run CHECK for trace, venue fit, safety, invariants/variants, and visible-render acceptance.
7. Project accepted output into `0-artifacts/`; reconcile projection edits back to the Page before acceptance.

Return the Artifact Page, projection path, handoff/render versions, acceptance state, and next action.
