# `probes` · route evidence acquisition through an Application Insight Page

This compatibility procedure has no Application-wide Probe pool.

1. Resolve the blocked Brief or Design Aim.
2. Run `missing-insight.md` and show the user-visible release packet.
3. Create or reuse one Page under `1-insights/<insight-id>/`.
4. Let that Insight Page search accepted Pages through PageX first.
5. Only the Insight Page may open its bounded `probe/` and acquire Task/Discovery
   evidence under Task-backed source, run, staleness, and human-reading rules.
6. Return an accepted Division 8 Design Handoff through PageX and reopen only the
   dependent Design divisions.

Do not create or migrate new work into `1-probes/`, a stage-local evidence pool,
or a Probe folder under Brief, Design, or Artifact Pages.
