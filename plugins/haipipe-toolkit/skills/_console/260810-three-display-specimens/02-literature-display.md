## Purpose

Can one matrix show which parts of the proposed relationship have already been studied and which
combination remains unoccupied within the reviewed corpus?
This Literature Display exists so the team can test its positioning before compressing that
positioning into prose or a paper figure.

## Reading

Five-second takeaway: adjacent links appear in prior work, but the complete chain is not represented
within the bounded corpus summarized here.
An empty cell means the cited study did not test that element under the coding rule.
It never means that no study anywhere has done so.

## Paper eligibility

decision: `transform`

The matrix is useful for internal judgment but too audit-heavy for the proposed paper story.
If Narrative selects C0, Paper Display should derive a simpler conceptual map from this matrix while
preserving a link to every citation binding.
The transformation must state what was removed and why; it must not silently turn bounded absence
into universal novelty.
