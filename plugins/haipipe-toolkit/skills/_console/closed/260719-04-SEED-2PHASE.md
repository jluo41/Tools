## 🆕 测试台抓到的新缺陷(不进清账表 —— 闭集不加号)

```
  entry 写 state: read,target 指向一个 state: answered 但 ## Answer 为空的 QA 文件
  (即"说谎的收据"),这个 entry 被报成 PASS。

  PASS 1 的 read-target 检查只测三种坏情况:working / superseded / 无 state 行。
  漏了第四种:answered 但答案是空的。
  → 论文可以宣称"我读了",而它读的东西里什么都没有。

  影响有限(PASS 3 会在 bank 侧把那个 QA 文件判 FAIL,整体 exit 仍是 1),
  所以这是【报告不精确】,不是假绿。但依赖谎言收据的那一条 entry 显示为 PASS,
  是会误导人的。修法一行:read-target 分支加一个 answered+空 Answer 的判定。
```
