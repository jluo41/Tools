📌  The case is BUILT, not found — Trigger · Key · CaseFn
═══════════════════════════════════════════════════════════════════

A record is one human's whole timeline. A CASE is one point cut from it —
one encounter, one review, one 5-min window. Three functions decide it, and
all three are selectable (that's the design frontier for the Case view).

─§ The three functions (haipipe fn_case/) ────────────────────────

  +----------------+----------------------------------------+------------------+
  | 🔧 Function    | 🎯 Decides                              | 🗂️ Lives in       |
  +----------------+----------------------------------------+------------------+
  | 🎯 TriggerFn   | WHICH moments become cases + the ObsDT  | fn_case/fn_trigger|
  | 🔑 Key         | how a case is IDENTIFIED (case_id_cols) | inside TriggerFn |
  | 🧩 CaseFn (×N) | WHAT facet each case carries            | fn_case/case_casefn|
  +----------------+----------------------------------------+------------------+

─§ How a case is assembled ───────────────────────────────────────

  🧑 Human(PID) timeline
       │  🎯 TriggerFn = ACIEncounterEntry   (one case per encounter)
       ▼
  📌 case  🔑 key = [PID · EncounterID · ObsDT]
       │
       ├─ 🧩 ACIDialogueBase  ─▶ the [doctor]/[patient] transcript
       ├─ 🧩 ACINoteBase      ─▶ the SOAP note
       ├─ 🧩 ACIContextBase   ─▶ chief complaint / demographics
       └─ 🧩 ACITranscript…   ─▶ ASR variants
                                 (CaseFn is a LIST — tick which facets show)

  swap the trigger → the same human re-cuts:
    🎯 ACIEncounterEntry ─▶ 1 case per visit
    🎯 CGM5MinEntry      ─▶ 1 case per 5-min point   (a long human → many cases)
    🎯 MimicAdmissionEntry ─▶ 1 case per admission
