WORKFLOW LAW
────────────

  Workflow       list of Run Specs + dependencies + Routes + completion rule
  Run instance   one allocated commission with Ticket · attempts · Result · receipt

  P0-P5           serialized capability tags retained for existing records/views
                  not workflow nodes, lifecycle owners, or route authority

  internal Step  PREPARE · JUDGE · LEARN · CLOSE, or GOLD · SCORE
                  actions inside a commissioned Run

  gate            predicate on a Run Spec transition, with evidence on its
                  owning Run receipt or named `resource_controls` record

  route           declared Run Spec outcome: another Run · HOLD · repair ·
                  rescan · semantic reopen · CLOSE

  item event      one human-first or final judgment

  round unit      rounds/round_<t>/ · card.md → README · manifest · evidence · prospect
                  → events → checkpoint.json → view/   (ref/ref-assets.md §3)
  register        register.md · seven regions × open / covered / risky

Pick, seal, label, rules, measure, and next are not independent Runs unless
they meet the shared Run commission and close-rule criteria.


THE CROSSING
────────────

  Building writes:  handoff/label-v1.yaml
  Scanning reads:   its exact checksum

  carries: corpus + schema + G* + D_cal* + sealed-test manifest checksum
           stopping evidence + lineage + human freeze signature

  never carries: protected test ids/text · drafts · model-majority gold


USER SURFACE
────────────

  /subjective-label              auto-route one next runnable action
  /label-building                the Building LAW · /label-building-workflow  the Building ORDER
  /label-scanning                the Scanning LAW · /label-scanning-workflow  the Scanning ORDER
  /subjective-label-workflow     Run Specs, dependencies, gates, Routes, crossing


STOP RULE
─────────

Stop at a human gate, implementation HOLD, invalidation, bounded action close,
or audited D*. Never convert silence, consensus, elapsed time, or a round limit
into semantic authority or a reliability claim.
