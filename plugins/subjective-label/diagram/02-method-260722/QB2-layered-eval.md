# 分三层考，别只看一个数
state: 🟡 PARTIAL
owner: RA
method: 三层 + 一层外部验证

## Question
改了一版规则，怎么知道它是真变好了，还是只是把看过的题背下来了？

## Diagram
```
  每改一版规则，同时报三个数：
    ① 标准答案上          改的东西起作用没
    ② 旧题上（标过但不在标准答案里）  有没有把旧规则改坏
    ③ 全新没见过的题上     换新数据还管用没（＝泛化）
  ── 再加一层 ──►  ④ 跟外部真人 / 公开数据比（见 QB3）

  实测的坑：同一版规则
     看过的题 → 一致度 0.93     ⬅ 只有第①层，还全取自作者标过的样本
     没看过的题 → 0.67          ⬅ 高分只是背下来了
```

## Now
版本迭代有，但**只有第①层**，而且那层的题全部取自 JL 自己标过的样本。
后果是实测出来的：同一版规则，在看过的题上一致度 0.93，换成没看过的题掉到 0.67 —— 高分只是把那些题背下来了。这是这块板上最有说服力的一个「为什么」。

## Done when
- [x] 有版本迭代（第①层：标准答案上）
- [ ] 每改一版同时报三个数（①标准答案 ②旧题上有没有改坏 ③没见过的新题上）—— 现在只有①
- [ ] 第①层的题别全取自作者标过的样本（现在 100% 重叠 → 制造了 0.93/0.67 陷阱）
- [ ] 再加一层：跟外部真人或公开数据比（这一层就是 QB3）

## Why here
JL：验证不能只看一个数，要分层跑「样例内 / 有没有改坏旧规则 / 泛化能力」这几组。

## Glossary
一致度 0.93 / 0.67：一个 0 到 1 的统计量，衡量两方打分有多一致，0 是瞎猜、1 是完全一样。0.93 看着很高，但如果只在「看过的题」上高，就是背下来了，不算数。
泛化：换一批从没见过的新数据，还标得准，才叫真的会标，而不是背答案。
