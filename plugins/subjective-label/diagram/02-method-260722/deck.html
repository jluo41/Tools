   你说：每条数据是空间里一个点，三个 label 就是三个区域。

        ┌─────────────────────────────────────────┐
        │        ●●●          ○  ○                │   ● 靠近中心 = clean case

        │        ●●●     ○      ○                 │
        │              ○  边界带  ○                │   ○ 在边界 = hard case
        │        ●●●  ○       ○   ●●●             │     模棱两可，约 20%
        │       ●LOW●    ○  ○    ●NONE●           │
        │        ●●●                ●●●           │
        └─────────────────────────────────────────┘

   你的两个判断：
   ① 「大部分都比较简单…难啃的可能占 20%」
      ⇒ 所以标注要**优先花在边界那 20%**，clean case 不值得占你的时间

   ② 「ground truth 一般是我们看不到的…我们设计的 guideline 跟真实的
      　一直有一个偏差，要不停更新，直到跟它差不多」
      ⇒ 真实的分界线你永远看不到，只能一版一版逼近它

   ③ 「假如你的点非常均匀地散出来，以至于边界附近非常非常多的点，
      　说明你的 guideline 说不清楚」
      ⇒ **边界带上挤了多少点**，本身就是规则清不清楚的指标
