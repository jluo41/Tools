# describe-medication + describe-insulin — worked API examples

GENERATED by `run_examples.py`. Do not hand-edit; re-run it instead.

Each folder is one real call against a live service: the request that went out,
the response that came back, and a note saying what the case is for.

    cd api/<case> && bash curl.sh

The two services are a CHAIN, not siblings. `describe-medication` resolves a
logged row to a `DrugKey`; `describe-insulin` consumes that string. Nothing can
tell whether MedicationID 612997 is insulin until it has been resolved, so the
order is fixed.
