这轮看到哪里

从共享 Focus 页面入口，追到导航、预览弹窗、等待托盘、通用章节组件和 Design 的目标／任务视图，再对照根规则和 UI 指南。检查的是当前工作区快照，不代表整个仓库没有其他问题。

审查方法

  • 先读 AGENTS.md、检查 git status；保留已有修改，只在本报告目录新增文件。
  • 区分源码事实、条件性风险与设计假设；每项保留文件位置和源码片段。
  • 共享交互由独立 Codex 审阅者进行只读复核，确认导航覆盖、弹窗命名和 Go 焦点问题的证据；该复核不是 Claude Code 审查，也不替代浏览器实测。
  • 静态检查包括源码摘录、文件摘要、颜色对比计算、生成页面结构、脚本语法和离线资源。验收步骤是后续真实页面的检查清单，并非已通过的测试。

原理怎么用

视频中关于密度、层级和克制的讨论在这里用作设计启发，不作为逐字转录或验收标准。把“高级感”落到可检查的选择：颜色能否读清、边界是否抢眼、标签是否重复、点击和焦点是否准确。涉及可访问性时，按条目链接的 W3C 原始说明核对。
