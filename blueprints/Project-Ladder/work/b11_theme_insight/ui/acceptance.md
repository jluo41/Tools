## New Task design acceptance

These checks apply to the proposal before a new Task type is implemented.

- One concrete enrichment Task, question-development Task and literature/theory Task each names its output and stop condition.
- Each identifies its current owning Block/Job or explicitly records that a new owner type is proposed.
- Data changes produce a new freeze; question changes enter a reviewed plan; closed Analysis Jobs remain pinned.
- The Board links each contribution to the question or conclusion it changes. A source collection alone does not constitute a synthesis.
- A reviewer can follow result → source → input/version and see uncertainty, disagreement or refusal.
