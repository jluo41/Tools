Two Blocks sit side by side in `insight/` (JL 261109): the **Question Book** (`InsightQuestionBook-<Topic>/`) holds the questions and their code, one signed question version (`question-vN`) at a time; the **Insight Board** (`Insight-<name>/`) runs a question version on a data version, one Job per pair. A "—" is a button that Block type does not have. The buttons are plain words; the key in a link stays: Findings is `answers`, Advice is `handoff`, Jobs is `jobs`.

Every view opens with 📋 Review Content, its numbered sections, then 🧭 Around the Work, the same eight shared sections as the Work theme (live since 261109). Every Report view ends with 🙋 Interaction. A Report view prints no caption line.

The question version × data version grid is 🧷 Jobs, on the Board's Jobs button: one Job is one question version on one data version, open until a person closes it. The Board's ✂️ Segments are those of the question version the newest Job runs. In the Question Book, ❓ Questions is the newest version's list, each question marked new or kept; Versions has one section per question version (its title is the version's own, `📜 question-vN` and its words): its sign state, what is new in it, its Segments, and Open. The question map is drawn one tab per question version in the Question Book, one tab per Job on the Board; Cards is its default, Dots its second drawing.

Use Cases opens source-backed pages grouped by SPACE. Project pages and Blueprint examples are labelled separately.
