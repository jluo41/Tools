The blueprint page

The Define UI: the workbench page of the plugin's blueprint Block. It shows the UI's definition, and every part of it links to a real page drawn from an example Block.

Examples, not mockups

An example Block is placeholder work in the real Work Folder shape. The page code draws it exactly as it would draw real work, so the definition is checked by the same code that serves the work. A mockup can drift from the pages; an example cannot.
