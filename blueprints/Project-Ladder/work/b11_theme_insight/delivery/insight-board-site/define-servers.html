Server folders

Part of the Define Folder: the page code is folders too. It lives in the plugin, never in a Block, and reads the Block folders each time a page opens to draw the Work UI.

The buttons

Every button is one card in haipipe-insight-workflow/ref/run-cards.md: its label, level and space, the Run it names, its skill, agent and signer, and the prompt it copies. run_cards.py --check checks every card against the scaffold's Run types; cards_table.py writes them all into workbench-insight/ref/workbench-table.md.

The shared frame

The page around the views is shared by every theme, in servers/workbench/page/: the focus page, the Folder view (frame_folders.py), the Session view (frame_sessions.py) and the marks. A theme fills its hooks; insight's element map is still to fill.
