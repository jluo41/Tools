Notes

  1. Runs moves into Work. The old Runs Space and the Runs panel become one Work view, so a Run is found where the work is.
  2. A Task's Work opens on Plan. Its old Description (Scope, Plan) is what it will do, so it belongs to Work.
  3. Same names everywhere. Report: MindMap · Status · Findings · Answers · Questions. Work: Progress · Runs · Results. A level shows only the views that have something; a theme adds at most two.
  4. A filter is never a view. Old buttons that only filtered rows become the word on each row.
  5. Guide, proposed: a small “?” beside the title opens it as a pop-out; it is no section and no view.
