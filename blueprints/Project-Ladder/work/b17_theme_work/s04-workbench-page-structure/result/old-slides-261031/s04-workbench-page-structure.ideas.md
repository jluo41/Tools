# s04 · Workbench page structure: ideas

The open ideas of this topic, one per slide: the question, the options side by side, which way we lean, what is still
unknown. Written in a round, by a person or the session; topic_slides.py draws it as slides (.slides.html, .slides.pptx).

## What is a Block, really?
- A topic: one subject in a Theme folder (haipipe-block today)
- A stage: one step of a pipeline, b00 raw to b31 endpoint (pipeline-blocks.md)
- A promise to one reader: one delivery, and the Questions it must answer for that reader
leaning: the third; the first two are ways the work was cut
ask: Does a data stage have a reader? Maybe the next Block is its reader.

## What are a Block's parts?
- Questions are the parts: Status counts answers (what the page did)
- Jobs are the parts; Questions are the contract that Jobs answer (answers: Q01)
- Fold Questions into Jobs: one Job, one question as its goal
leaning: the second
ask: What about a Job that serves every Question, like j01's shared tables?

## What is a Studio?
- The plan stage, before Work
- A separate place to think, beside Report and Work
- The discussion itself: rounds (sessions, meetings) that loop through Work and Report and come back
leaning: the third
ask: Does every session need a home topic, named at its start?

## How does a round leave the Studio?
flow: round → Work (Started) → Report (Answered) → back to the Studio (Next)
- To Work: a decision starts a Job, a Task or a Run
- To Report: a decision answers a Question
- Back to the Studio: what is still open becomes the next round
ask: Should a Run card point back to the round that started it (from: s04 p02)?

## If you keep only one screen of a Block
- The Mindmap: how it is built
- The Findings: what it found, in its answers' own words
- A Block card: For, Takes in, Done when, How far, Next move; then one row per Question
leaning: the Block card (ui-draft-v7)
ask: Is "Next move" enough to answer "what do I do now"?

## How big may a Studio grow?
- No limit: every thought gets a topic
- A cap per level: Block 10, Job 3, Task 2
- One topic per open question; closed topics fold away
ask: Is a cap a rule, or only a warning?
