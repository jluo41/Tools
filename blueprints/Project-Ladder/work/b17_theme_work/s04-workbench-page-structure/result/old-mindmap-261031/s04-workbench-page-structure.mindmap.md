# Workbench page structure <!-- root -->

Design discussion. Agreed = stated requirements; proposal = not yet accepted; open = a decision for the page owner.

- [structure] Read the page from top to bottom <!-- n01 -->
  → What should appear immediately below the introduction?
  - [agreed] The path comes first. <!-- n02 -->
  - [agreed] Introduce the current Block or location below it. <!-- n03 -->
  - [open] Choose what comes below the introduction. <!-- n04 -->
  - [proposal] Keep the path and introduction stable across sections. <!-- n05 -->
- [navigation] Give each edge one clear purpose <!-- n06 -->
  → How do we keep navigation quiet without losing context?
  - [open] Should the left edge show siblings or children? <!-- n07 -->
  - [proposal] Use the left edge for siblings at the current level. <!-- n08 -->
  - [open] Which sections belong on the right, and where does Guide go? <!-- n09 -->
  - [proposal] Show Run types only within execution content. <!-- n10 -->
  - [agreed] Short bars reveal names on hover; remove the Focus mode selector. <!-- n11 -->
- [content] Keep related information attached <!-- n12 -->
  → What lets the reader understand progress and inspect the result?
  - [agreed] Use one full-width row per item. <!-- n13 -->
  - [agreed] Show one section at a time. <!-- n14 -->
  - [agreed] Show important text and figures directly, without disclosure clicks. <!-- n15 -->
  - [proposal] Keep each Job goal, status and output together. <!-- n16 -->
  - [proposal] Keep each figure with its caption, owning Task, Run and review. <!-- n17 -->
  - [proposal] Distinguish execution completion from goal acceptance. <!-- n18 -->
  - [open] What evidence separates recorded status, live execution and accepted results? <!-- n28 -->
- [hierarchy] Preserve context at all five levels <!-- n19 -->
  → Which information belongs at each level?
  - [agreed] The hierarchy is Project, Theme, Block, Job, Task. <!-- n20 -->
  - [proposal] Put direct children in the main content with their goals and status. <!-- n21 -->
  - [proposal] Adapt sections to the current level rather than copying one template. <!-- n22 -->
  - [open] Should a Block open on its Jobs' goals and statuses? <!-- n23 -->
  - [open] Which sections belong at each level? <!-- n29 -->
