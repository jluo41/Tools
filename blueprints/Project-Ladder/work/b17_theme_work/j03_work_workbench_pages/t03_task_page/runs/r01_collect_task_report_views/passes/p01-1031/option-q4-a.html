One topic, one idea, one delivery (261030)

A Studio runs from idea to delivery (JL 261030: "studio: from idea to delivery"; "one studio, one idea and one delivery"). Each topic, s01 as much as s07, holds one idea and ends in its own delivery, named first on its face (For:, "so one studio should link to a delivery, this is the outcome oriented"). A Block's delivery is its topics' deliveries together, listed in its board.md ## Deliveries.

The thing is one clean thing of one type: a skill, a draft, a display, workbench code, a data table, a server package (JL 261030: "so each studio with a clear delivery, right? either skills or draft, or display"). A mixed delivery is several sNN, one per type; no clean delivery, no sNN ("is the delivery is not clean or is not one type, we will not treat it as a studio"). b35 went from seven sNN to three this way (b35 board.md ## Deliveries).
