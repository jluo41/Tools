One Run page for every theme. A Run shows the same four parts wherever it sits; its use case is its `run.yaml` `type:`, whichever theme it serves.

A Run has no Around the Work of its own: its Studio, Interactions and Decisions belong to the page above it.

Data in and out shows only when the Run has `result/data-card.yaml`; a Task's Runs fold the same card under each row.

Hard and soft Runs share the page. A collection Run's ticket is its form, and its result is the answers.
