# Paper matrix validation

## Scope

The current matrices describe one implemented Paper Board contract, one proposed Grant Board contract, five Job renderer branches and eight Task presentation branches. Writing-version revisions, draft purposes and whole-paper audit scopes are Use Cases, not additional UI types. Dispatch evidence is recorded in `structure.md`.

The matrices use the shared transposed layout and Use Cases popup. A shared column-layout correction reserves space for the sticky view column and gives type columns a readable minimum width within a horizontally scrolling container. No external SPACE service was changed for this update.

## Verified

- All 23 Paper Use Cases resolve to a Blueprint example. Local configuration currently adds project examples to 21 cases.
- Every referenced page has its native face and actual Block / Job / Task ancestry. Expanded Task lists contain only direct child Tasks of the selected Job.
- Each use-case template contains the expected source groups, hierarchy links and collapsible Path. This is a renderer check, not a browser-click check.
- All 49 remaining Section/example routes select a view present in the target page's navigation.
- Fourteen focused matrix, UI and Use Cases regression tests passed.
- Public matrix definitions contain only Blueprint paths. Cross-SPACE roots and project paths are stored in ignored local configuration; unrelated matrix keys are preserved.
- All 34 distinct retained project example URLs and the three Paper matrix pages returned HTTP 200. A configured source that refused connections was excluded without restarting its service.
- Independent source review checked classification, source mappings and privacy separation.

## Coverage limits

Reviewer response and whole-paper value audit currently have Blueprint examples only. A configured address and an existing folder do not by themselves establish that a source page is reachable.

Project links open each SPACE's current service. Their availability does not establish deployment of the new common frame, acceptance of a manuscript, or approval to submit it. Job and Task shared-frame migration remains open.

The coordinating Work session opened and closed all 23 Paper Use Cases without empty results, expanded Tasks and Path, and checked that switching cases leaves no stale content. It followed six project pages covering Block, Job and Task on two sources; all reached the intended pages. The two Blueprint-only cases were confirmed in the browser.

Desktop review initially found the sticky view column covering part of the first type column and overly narrow Task columns. After the shared correction and Tools service reload, browser revalidation at a measured 1280 px viewport confirmed a 130 px view track followed by 180 px type tracks, with no initial overlap. The 1570 px Task table scrolls within its 818 px container; the final type's Use Case opens correctly and scrolling back restores the first type. A Work Job matrix was also checked at 1017 px: its columns and popup remain usable. Independent source review found no required correction in the layout patch.

Phone acceptance remains pending: the attempted 390 px resize left the actual viewport at 1280 px. HTTP and renderer checks do not substitute for that walk.
