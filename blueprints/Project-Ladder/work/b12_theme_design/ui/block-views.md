A "—" is a button that Block type does not have. The Board's buttons are plain words, paired with the insight Board's (JL 261109): Designs was Summary, Rounds was Jobs, Inputs was Rounds, Tests was Methods; an older link opens its new view. A Board with a Book leaves the method scorecard to the Book's Scorecard.

Names: `design/DesignMethodBook-<Topic>/` with one Job per release `jNN_method-vN_<slug>/` and its backlog in `proposals/`; `design/Design-<name>/` names its Book with `method-book:`, and each Job runs one release (`release: method-vN`) on one inputs version, `jNN_<goal>_method-vN-<slug>_inputs-vM/`.

Report contains **Review Content**, then eight unnumbered **Around the Work** sections. Work bookmarks open the matching Report view. Delivery remains a separate rail entry.

Older Design Folder boards retain their legacy page and are outside this matrix.
