related · what this Block sits beside
=====================================

One row per item, any kind (meeting · paper · file · email · repo · dataset · tool · project). A
meeting's notes go in `meetings/`, an open-licensed PDF in `papers/`, a file we were sent in `files/`,
an email saved as it came (`.eml`) in `emails/`; anything else is only a row with its link. What lands
here is not edited again; notes about it go to a studio topic or a report (s01-D34). A subfolder is a
group of its files; more groups go in the `group` column, comma-separated; `_groups.txt` keeps their
order (s04-D07, D08). The skill is `/haipipe-related`.
