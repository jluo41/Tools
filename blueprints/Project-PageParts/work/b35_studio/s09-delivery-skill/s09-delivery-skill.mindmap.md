# Delivery skill: built, accepted, sent

How reviewed working material becomes a versioned delivery that someone can use.

- [workflow] The total workflow <!-- n01 -->
  - [step] Identify the owner <!-- n02 -->
    Name the Studio or work level that owns the product.
  - [step] Select the clean version <!-- n03 -->
    Choose the reviewed material. Keep experiments in result.
  - [step] Build from source <!-- n04 -->
    Generate the product, its preview and explanation deck. Never hand-edit generated output.
  - [step] Place at destination <!-- n05 -->
    Map each piece to its intended use; render text or use the owning code builder.
  - [step] Check and hand over <!-- n06 -->
    Open the real product, verify links and versions, and let a person mark acceptance or sending.
