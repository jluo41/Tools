# Job Work views

for: b35.j02.t03-s15

The Work section of a Job page (j02_studio_pages): its view buttons, what each view holds, and what a click does. Previews use j02's real Tasks and Runs.

## Q1 · View list

Today Work has one view, Progress: one row per Task. A Job's Tasks each hold Runs; the Job hands over s02's delivery.

**Which view buttons should a Job's Work have?**

- [x] A · Tasks · Runs: the Tasks, then every Run of those Tasks.
  [preview](q1-a.html)
- [ ] B · Tasks only: each Task row lists its Runs on one line.
  [preview](q1-b.html)
- [ ] C · Waits on you · Open · Done: the Tasks split by state word.
  [preview](q1-c.html)
- [ ] D · Tasks · Runs · Deliverables: adds what the Job hands over.
  [preview](q1-d.html)

Why A: Work does its children and Runs; two views, no repeats.
