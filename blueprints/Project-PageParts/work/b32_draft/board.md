## Topic

JL 261011: "How do we really think about haipipe-page, it is more like the haipipe-draft, which
contains the logic, sentences, and evidence, and have a subfolder of draft to work on." What the Page
skills manage today is a draft: its logic (the outline plan, one Bullet per point with its Role),
its sentences (the Content, each sentence addressable, haipipe-draft-writing) and its evidence (typed
Evidence Items bound to Results), worked on in the folder's `draft/` (plan versions, Scratch,
Revise, records) and built into the Block's `delivery/`. The Page is the face a reader opens. This
Block asks whether the base layer should be named and taught as the Draft, what a draft folder
holds, and how every theme (a paper Section, a report, a cowork email, a discovery or insight page)
uses the same draft.

Excluded: the ladder and the shared screen (b10_project_workbench); each theme's own Page Types
(b11 to b17 keep theirs); renaming a real Project's folders before JL agrees.
