# Takeaways

## draft lab
- Each sentence is the unit; its cards and comments sit right below it.
- A ✓ tick means keep it: no more proposals; changed words show ✓?.
- Fully ticked paragraphs start folded; only paragraphs fold, never whole Sections.

## paper text
- Edits stay small and keep the co-authors' wording and paragraph structure.
- Paragraphs hold 4 to 6 sentences, by moving or merging, never filler.
- Fewer sentences start with "We"; citations follow APA 7 style.

## process & coordination
- One Claude session owns one Section; the main session owns the build.
- Work on the LaTeX first; the Word file is the last step.
- The AI makes real tracked changes, not comments, and checks them first.

## evidence & displays
- Section evidence points to the Block-level records, never copies them.
- A display shows under its citing sentence, only where it first prints.
- Figure 1 stays minimal: construct boxes and two hypothesis arrows only.

## review & scoring
- A fresh blind reviewer scores each sentence, never the one who wrote it.
- A sentence scoring below 7 gets an edit card; checked sentences show no score.
- A Section closes only after an independent check passes.

## page layout
- Pages show no tallies and no status words; marks and layout show state.
- A Section page opens on Draft; a version page opens on Structure.
- Write and Revise merge into one Draft view; extra views are dropped.

## versions & delivery
- Submit the PDF from the journal's official LaTeX template, within 55 pages.
- Changes show as a LaTeX diff against the previous round, with margin notes.
- Each round's OneDrive folder holds the Word file, the PDF and the diff.

## code quality
- Split files over the 600-line limit; commit only after tests pass.
- A fresh reviewer checks the code, tested against real Boards.
- Each session commits only its own files, never another session's work.
